自宅サーバーやNASを使い始めると、次に気になるのが「ファイル転送が遅い」問題です。多くの家庭内LANは今も **1GbE（1Gbps）** が上限で、これは実効で毎秒約110MB前後。大容量の動画やバックアップを扱うと、ここが確実にボトルネックになります。

そこで現実的な解が **2.5GbE化** です。10GbEより圧倒的に安く、既存のLANケーブル（カテゴリ5e以上）をそのまま使えるのが最大の利点です。

ただし、**2.5GbEにしても速くならないケースがあります**。この記事では、必要な機材と費用に加えて、「そもそも速くなるのか」を先に判断する方法から説明します。

## その前に：本当にネットワークがボトルネックか

「転送が遅い＝LANが遅い」とは限りません。実際には、次のどれかが上限を作っています。

| 部位 | 実効速度の目安 |
|---|---|
| 1GbE ネットワーク | 約110MB/s |
| **2.5GbE ネットワーク** | **約280MB/s** |
| 10GbE ネットワーク | 約1,100MB/s |
| 3.5インチHDD（単体） | 100〜250MB/s |
| SATA SSD | 約500MB/s |
| NVMe SSD（Gen3） | 1,500〜3,500MB/s |
| USB 2.0 の外付けHDD | 約35MB/s |
| Wi-Fi 5（実効） | 30〜80MB/s |
| Wi-Fi 6（実効・近距離） | 100〜200MB/s |

ここから分かる重要な点が2つあります。

**1. 転送元・転送先がHDD単体なら、2.5GbEにしても頭打ちになります。** 3.5インチHDDの実効速度は連続読み書きで150MB/s前後。1GbE（110MB/s）よりは速いので多少の改善はありますが、2.5GbEの280MB/sは活かしきれません。**2.5GbEが本領を発揮するのは、両端がSSDか、HDDを複数台束ねたRAID構成の場合です。**

**2. Wi-Fi接続のPCを速くしたいなら、まず有線化が先です。** Wi-Fi 5 の実効速度は1GbE有線にも届きません。LANケーブルを1本引く方が、はるかに安く効果的です。

### 自分の環境を測ってみる

現状を数字で把握しておくと、投資すべき箇所が分かります。

```bash
# Linux/NAS間で iperf3 を使ってネットワーク速度だけを測る
# 受信側
iperf3 -s
# 送信側（NASのIPを指定）
iperf3 -c 192.168.1.10
```

`iperf3` はディスクを介さずネットワークだけを測るため、**「LANが遅いのか、ディスクが遅いのか」を切り分けられます**。1GbE環境なら 940Mbps 前後が出ていれば正常。ここが正常なのにファイルコピーが遅いなら、原因はディスク側です。

## 結論：2.5GbE化に必要なのは3つだけ

2.5GbEの速度を出すには、経路上のすべてが2.5GbE対応である必要があります。逆に言えば、揃えるのは次の3点だけです。

1. **2.5GbE対応スイッチ**（ハブ）
2. **各機器の2.5GbE化**（NIC増設 or USBアダプタ）
3. **カテゴリ5e以上のLANケーブル**（多くの既存ケーブルで流用可）

## 選び方のポイント

### 1. まずは「NAS〜PC間」だけ2.5GbE化する

家じゅうを一気に速くする必要はありません。効果が最も大きいのは **NAS（またはサーバー）と、よく使うPCの間**。この2点とスイッチだけ2.5GbEにすれば、体感は大きく変わります。ルーターやその他の機器は1GbEのままで問題ありません。

**さらに安く済ませる方法**として、スイッチを買わずに **NASとPCを直結する**という手もあります。それぞれに2.5GbEのポートが2つある場合、片方を既存のLANに、もう片方を相手と直結すれば、スイッチ代（1万円前後）が浮きます。IPアドレスを手動で設定する必要はありますが、費用対効果は最も高い構成です。

### 2. 機器の2.5GbE化は「スロットの有無」で選ぶ

- デスクトップ／PCIeスロットのあるミニPC → **増設NIC（Intel I226-V）** が安くて安定
- ノートやスロットのない小型機 → **USBアダプタ** が手軽

Intel の I225/I226 系チップは自宅サーバー界隈で実績が多く、Proxmox や TrueNAS などでも標準で認識されるためおすすめです。

**注意点**：I225 の初期リビジョン（v1/v2）には、リンクが不定期に切断される既知の問題がありました。中古や古い在庫を買う場合は、**I226 世代を選ぶ**か、ファームウェアが更新済みかを確認してください。

USBアダプタを選ぶ場合は、**USB 3.0（5Gbps）以上のポートに挿すこと**が必須です。USB 2.0（480Mbps）に挿すと、2.5GbEどころか1GbEにも届きません。青いポート、または「SS」マークのあるポートを使ってください。

### 3. ケーブルは「カテゴリ5e以上」ならOK

2.5GbEはカテゴリ5eで規格上問題なく通ります。今使っているケーブルが5e/6であれば買い替え不要です。新規で買うならカテゴリ6を選んでおけば将来の10GbEにも備えられます。

**カテゴリ7・8は自宅では推奨しません。** これらは本来STP（シールド付き）での運用を前提としており、家庭用機器のようにアース処理がされていない環境では、かえってノイズを拾って不安定になることがあります。**カテゴリ6か6AのUTP（非シールド）で十分**です。

### 4. スイッチは「ファンレス」を選ぶ

自宅の居室に置くなら、ファンレス（無音）モデルを選んでください。安価な業務用スイッチには小径ファンが付いており、常時稼働では耳障りです。

2.5GbEスイッチの消費電力は5ポートで5〜10W程度。31円/kWh・常時稼働で**年間1,360〜2,700円**です。

## 費用の目安

| 構成 | 内訳 | 費用の目安 |
|---|---|---|
| **最小構成**（NAS↔PC直結） | USBアダプタ × 2 | 6,000〜7,000円 |
| **標準構成** | 5ポートスイッチ + NIC/アダプタ × 2 | 13,000〜19,000円 |
| **拡張構成** | 8ポートスイッチ + NIC × 3〜4 | 25,000〜35,000円 |

10GbE一式（スイッチだけで2〜3万円〜）と比べて大幅に安く、体感の伸びは十分大きいので、**最初の高速化は2.5GbEから始めるのが失敗しません**。

## 導入後に速度が出ないときの確認手順

「機材を揃えたのに速くならない」というときは、上から順に確認してください。

1. **リンク速度を確認する** — OS側で 2500Mbps でリンクしているか。1000Mbps のままなら、ケーブルかポートの問題です。
   ```bash
   # Linux の場合
   ethtool enp1s0 | grep Speed
   ```
2. **iperf3 でネットワーク単体を測る** — 2.3Gbps 前後出れば、ネットワークは正常です。
3. **ディスク速度を測る** — ネットワークが正常なのに遅いなら、原因はディスク側です。
4. **ケーブルを疑う** — 古い自作ケーブルや、爪の折れたコネクタは接触不良を起こします。別のケーブルで試してください。
5. **発熱を確認する** — USBアダプタは高負荷時に発熱し、速度が低下することがあります。長時間の転送で徐々に遅くなる場合はこれが原因です。

## よくある質問

**Q. 2.5GbEと10GbE、どちらにすべき？**
NAS 1台と数台のPCで使う一般的な自宅環境なら、まず2.5GbEで十分です。10GbEは、複数の高速SSDを束ねたNASや、仮想マシンのディスクイメージをネットワーク越しに置くような用途で明確に必要になってから検討すれば無駄がありません。詳しくは [自宅10GbE化の完全ガイド](/articles/home-10gbe-network-guide/) をご覧ください。

**Q. スイッチだけ2.5GbEにすれば速くなる？**
なりません。速度は経路の最も遅い部分に律速されるため、**NAS側・PC側の両方**も2.5GbE化する必要があります。

**Q. ルーターも2.5GbE対応にすべき？**
インターネット回線が1Gbps契約なら不要です。ルーターを通るのは外部との通信だけで、**家庭内のNAS↔PC間の通信はスイッチ内で完結します**。10Gbpsの回線契約をしている場合のみ、ルーター側のWANポート速度が意味を持ちます。

**Q. 発熱は大丈夫？**
2.5GbE機器は1GbEより発熱します。スイッチは風通しのよい場所に置き、USBアダプタは金属筐体のモデルを選ぶと安定しやすくなります。

**Q. 既存の壁内配線が古いのですが？**
築年数の古い住宅では、壁内がカテゴリ5（5eではない）の場合があります。カテゴリ5は規格上1GbEまでで、2.5GbEはリンクしないか不安定になります。ケーブルの外皮に「CAT5」「CAT5e」の表記があるので確認してください。

## まとめ

- **投資の前に、ボトルネックがネットワークかディスクかを `iperf3` で切り分ける**
- HDD単体が相手なら2.5GbEの効果は限定的。**両端がSSDまたはRAIDのときに効く**
- 必要なのは「スイッチ・各機器のNIC・カテゴリ5e以上のケーブル」の3点
- **NASとPCの直結**ならスイッチ代を節約できる
- NICは **Intel I226 系**が無難。USBアダプタは必ずUSB 3.0以上のポートへ
- ケーブルは**カテゴリ6のUTPで十分**。カテゴリ7以上は自宅では推奨しない
- 標準構成で **1.5〜2万円**。10GbEより大幅に安い

機材が決まったら、NAS側の構成は [自宅NASおすすめ比較](/articles/home-nas-comparison-2026-synology-qnap-diy/) もあわせてご覧ください。

## 自宅のLAN配線、カテゴリ選びで何が変わるのか

NASやミニPCサーバーを自宅に置き始めると、必ずぶつかるのが「LANケーブルは何を買えばいいのか」という問題です。家電量販店やECサイトを見ると、CAT5e・CAT6・CAT6A・CAT7・CAT8と似たような製品がずらりと並び、価格も1mあたり数十円から数百円まで幅があります。

結論から言うと、2026年現在の自宅配線で中心に考えるべきは**CAT6A**です。CAT8は魅力的なスペックに見えますが、家庭のLAN環境ではほぼ性能を使い切れず、配線のしやすさでもCAT6Aに劣ります。この記事では、その理由を数字と施工面の両方から解説します。

## カテゴリ別スペック早見表

まずは主要カテゴリの公開仕様を一覧にします。

| カテゴリ | 最大通信速度（規格上） | 伝送帯域 | 最大配線長の目安 | 主なコネクタ | 自宅での位置づけ |
|---|---|---|---|---|---|
| CAT5e | 1Gbps | 100MHz | 100m | RJ45 | 旧世代・在庫処分品が中心 |
| CAT6 | 1Gbps（10Gbpsは短距離のみ） | 250MHz | 100m（10Gbpsは約55m） | RJ45 | 1GbE環境なら十分 |
| CAT6A | 10Gbps | 500MHz | 100m | RJ45 | 自宅10GbEの標準的な選択肢 |
| CAT7 | 10Gbps | 600MHz | 100m | GG45/TERA（RJ45変換も流通） | 規格上は高性能だがRJ45非対応が多く扱いにくい |
| CAT8 | 25〜40Gbps | 2000MHz | 30m | RJ45（Class I）／TERA・GG45（Class II） | データセンター・短距離の超高速用途向け |

ポイントは「最大配線長」です。CAT8は25G/40Gbpsを出す条件下では**30m程度までしか保証されない**規格です。一方CAT6Aは10GbEであれば100mまで仕様上カバーします。自宅内の配線（ラックからルーターまで、各部屋までの壁内配線など）は数mから長くても30〜40m程度に収まることが多く、この範囲ではCAT6Aで規格上の性能を引き出せます。

## CAT6AとCAT8、何がどう違うのか

### 通信速度と実用上の差

家庭用スイッチやNICで一般に流通しているのは1GbE・2.5GbE・10GbEまでです。25GbEや40GbEに対応する家庭向け機器はまだ非常に限られており、価格も業務用に近い水準です。つまり**CAT8が持つ25〜40Gbpsという性能を自宅で使い切れる環境は、2026年時点ではごく一部のハイエンドhomelabに限られます**。

10GbE止まりの機材構成であれば、CAT6AとCAT8のどちらを使っても通信速度は変わりません。速度面でCAT8を選ぶ積極的な理由は、将来25GbE以上に機材を更新する計画が明確にある場合に限られます。

### シールド構造と取り回し

CAT6Aは「UTP（シールドなし）」と「STP/F-UTP（シールドあり）」の両方が流通しています。自宅配線でノイズの影響が少ない環境（家電からの距離が十分ある、配線が短い）であればUTPでも実用上問題ないケースが多く、ケーブルが柔らかく取り回しやすいという利点があります。

一方CAT8は規格上シールドが必須（Class I/II規格ともにシールドあり）です。シールド層がある分ケーブルが太く硬くなりやすく、壁内配線や狭い配線スペースでは取り回しに苦労しがちです。アース処理も必要になる場合があり、DIYでの施工難易度はCAT6Aより高くなります。

### 価格差を具体的な配線で計算する

自宅の配線でよくある「ラックから別部屋の壁コンセントまで15m」のケースで、ケーブル代だけを比較してみます。

```
CAT6A（約120円/m）: 120円 × 15m = 1,800円
CAT8（約350円/m）:  350円 × 15m = 5,250円
差額: 3,450円
```

これを家全体で4本（寝室・書斎・リビング・サーバーラック用）配線すると仮定すると、

```
CAT6A: 1,800円 × 4本 = 7,200円
CAT8:  5,250円 × 4本 = 21,000円
差額: 13,800円
```

となり、CAT8を選ぶと1万円以上の追加コストがかかる計算です。この差額に見合うだけの速度メリットを、自宅の実際の用途（NASへのバックアップ、動画編集データの転送など）で得られるかどうかを事前に考える必要があります。

## 用途別の選び方早見表

| 用途・環境 | おすすめカテゴリ | 理由 |
|---|---|---|
| 1GbEルーター＋一般的な動画視聴・ゲーム | CAT6（在庫があれば） | 1Gbpsで帯域が頭打ちになるためオーバースペック不要 |
| NASやミニPCサーバーで10GbEを組みたい | CAT6A | 10GbE規格上100mまで対応、価格も現実的 |
| ラック内の短距離配線（1m前後）で将来25G/40Gも見据える | CAT8 | 短距離ならシールドの取り回しづらさが影響しにくい |
| 壁内配線・DIYでの長距離配線 | CAT6A（UTP） | 柔らかく扱いやすい、アース不要なモデルが多い |
| すでにCAT6で1GbE運用中、不満がない | 交換不要 | 用途に対して十分な性能が出ている |

## つまずきポイント

実際にLANケーブルを選び替える・配線し直す際に詰まりやすい点をまとめます。

- **「CAT6Aケーブルなのに10Gbps出ない」**：ケーブルがCAT6A対応でも、途中のスイッチングハブやNIC、壁内のモジュラージャックが1GbEやCAT6対応のままだとそこがボトルネックになります。配線経路すべての機器・部材のカテゴリを揃える必要があります。
- **既設の壁内配線がCAT5eだった**：賃貸や築年数の古い住宅では壁内配線がCAT5eのままのことがあります。壁を開けずに10GbE化したい場合は、無線（Wi-Fi 6E/7）や電力線通信（PLC）、あるいは露出配線での引き直しを検討することになります。
- **シールド付きケーブルのアース未接続**：CAT6A/CAT7/CAT8のシールドタイプは、コネクタ部でアースが適切に取れていないとシールドが機能せず、かえってノイズの影響を受けることがあります。自作でコネクタを圧着する場合は特に注意が必要です。
- **ケーブルの曲げ半径を無視した無理な配線**：規格上、ケーブル径の4〜8倍程度の曲げ半径を推奨している製品が多く、きつく曲げると伝送性能が落ちたり断線の原因になります。太いCAT8ケーブルほどこの制約が効いてきます。

## 配線後の確認方法

配線やケーブル交換が終わったら、実際にリンク速度が出ているか確認しましょう。Linuxサーバーやミニサーバーであれば、以下のコマンドで物理リンクの速度を確認できます。

```bash
# NICのリンク速度を確認（例: eth0）
ethtool eth0 | grep Speed

# 期待する出力例
# Speed: 10000Mb/s
```

リンク速度は出ているのにファイル転送が遅い場合は、実効スループットを計測します。

```bash
# 計測用サーバー側
iperf3 -s

# クライアント側（30秒間計測）
iperf3 -c 192.168.1.10 -t 30
```

ここで理論値（10GbEなら約1.25GB/s）に対して実測が大きく下回る場合は、ケーブルよりもディスクI/Oやスイッチの設定（ジャンボフレームの有無など）がボトルネックになっているケースが多く、ケーブルを闇雲に高カテゴリへ交換しても改善しないことがあります。

## 買わなくていい・交換不要なケース

すべての家庭がCAT6Aにする必要があるわけではありません。以下のような場合は、今のケーブルのままで問題ないことが多いです。

- インターネット回線自体が1Gbps契約で、NASやサーバーも1GbE機器しか持っていない場合。CAT6のままで帯域を使い切れていないことはまずありません。
- 動画や大容量ファイルのやり取りが月に数回程度で、転送に多少時間がかかっても困らない場合。
- 配線距離が短く（2〜3m程度）、現状のケーブルで通信エラーや速度低下が体感・計測上出ていない場合。

逆に、NASへのバックアップや4K/8K動画素材の転送を日常的に行っていて「転送待ちがストレスになっている」場合は、CAT6Aへの張り替えとNIC・スイッチの10GbE化を合わせて検討する価値があります。

## よくある質問（FAQ）

**Q. CAT6AケーブルをCAT5e対応の機器につないでも使えますか？**
A. 使えます。LANケーブルは下位互換性があり、CAT6Aケーブルを1GbE機器に接続しても1Gbpsで動作します。将来の機器更新を見据えて先にケーブルだけCAT6Aにしておく、という選択も合理的です。

**Q. CAT7は自宅で使っても問題ないですか？**
A. 規格上の性能は高いものの、本来のCAT7はGG45やTERAという専用コネクタを前提としており、一般的なRJ45機器では規格通りの性能を保証されません。市販の「CAT7対応」を謳うRJ45ケーブルは実質的にCAT6A相当として扱われることが多く、積極的に選ぶ理由は薄いです。

**Q. 自宅の壁内配線を自分でCAT6Aに交換できますか？**
A. LANケーブルは弱電（通信用）の配線なので、LANケーブルの敷設やLANモジュラージャックの取り付け自体には電気工事士の資格は不要です。ただし、電源コンセントの増設・移設や、電源と一体になったマルチメディアコンセントの交換など、100Vの電源配線に触れる工事を伴う場合は電気工事士の資格が必要です。その場合は資格を持つ業者に依頼してください。なお、壁内の配管に通線できるかどうかは住宅の構造次第で、露出配線（モールなどを使う）であればDIYの難易度は下がります。

**Q. ケーブルの長さはどう決めればいいですか？**
A. 配線予定ルートを実測し、曲げる箇所やコネクタ接続の余裕分として1〜2m程度を上乗せするのが一般的です。短すぎて突っ張った状態になるとコネクタ部に負荷がかかり接触不良の原因になります。

**Q. 無線LAN（Wi-Fi 6E/7）があれば有線LANは不要ですか？**
A. 無線は距離や障害物、電波干渉の影響を受けやすく、NASへの大容量バックアップなど安定した帯域が必要な用途では有線の方が有利です。日常のネット利用は無線、サーバー・NAS周りは有線、という使い分けが現実的です。

## まとめ

自宅のLAN配線を見直すなら、2026年時点での現実的な選択肢は**CAT6A**です。10GbEまでの速度を100mの配線長までカバーでき、価格もCAT8の3分の1程度に収まります。CAT8は規格上の性能こそ高いものの、対応機器がまだ限られること、シールド構造で施工難易度が上がること、価格が大きく跳ね上がることから、よほど明確な高速化計画がない限り自宅用途ではオーバースペックになりがちです。

まずは自宅の回線契約・NASやミニPCサーバーの対応速度を確認し、それに見合ったカテゴリを選ぶことが、無駄なコストをかけない配線選びの第一歩になります。

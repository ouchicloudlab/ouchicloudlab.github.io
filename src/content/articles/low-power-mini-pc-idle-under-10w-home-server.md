## はじめに：おうちサーバーこそ「アイドル電力」が重要

Jellyfin、Home Assistant、Pi-hole、自宅NASなど、24時間365日稼働させる「おうちサーバー」で最も効いてくるコストは、実は本体価格よりも電気代です。ピーク性能ではなく、**待機状態（アイドル時）の消費電力**がどれだけ低いかが、年間の電気代を決めます。

自宅サーバーの稼働時間の内訳を考えると、その理由がはっきりします。Pi-hole や Vaultwarden のような軽量サービスを動かしている場合、CPUが実際に仕事をしているのは**1日のうち数分から数十分**です。残りの23時間以上は、ほぼ何もしていない状態で電力を消費し続けています。

## まず、電気代を自分で計算できるようにする

計算式は単純です。

```
1年間の電気代（円） = 消費電力(W) × 24時間 × 365日 ÷ 1000 × 電力量料金(円/kWh)
```

電力量料金を **31円/kWh** として計算すると、次のようになります。

| アイドル消費電力 | 年間消費電力量 | 年間の電気代 | 5年間の電気代 |
|---|---|---|---|
| 6W | 52.6kWh | 約1,630円 | 約8,150円 |
| 8W | 70.1kWh | 約2,173円 | 約10,865円 |
| 10W | 87.6kWh | 約2,716円 | 約13,580円 |
| 15W | 131.4kWh | 約4,073円 | 約20,365円 |
| 20W | 175.2kWh | 約5,431円 | 約27,155円 |
| 45W（中古デスクトップ相当） | 394.2kWh | 約12,220円 | 約61,100円 |

ここから読み取れる**重要な事実**があります。

**省電力機どうしの差は、思ったほど大きくありません。** 6Wと10Wの差は年間で約1,086円、5年でも約5,430円です。本体価格の差がそれ以上なら、電気代を理由に安い方を選ぶ意味は薄いということになります。

**一方、20W以上との差は決定的です。** 10Wと45Wの差は年間約9,500円。5年で約4.8万円になり、ミニPCが1台買える金額です。「余っている古いPCを流用すればタダ」という発想が成立しないのは、この差によるものです。

> ※上記は電力量料金単価31円/kWhでの試算です。実際の請求額は契約プラン・燃料費調整額・再生可能エネルギー発電促進賦課金により変動します。

## 選び方のポイント

### 1. CPUアーキテクチャで消費電力が変わる

Intel の N100・N150 シリーズは TDP 6W 前後の設計で、アイドル電力の低さに直結します。一方、AMD Ryzen の高性能モデルは処理性能が高い反面、アイドル時でも10W台になりやすい傾向があります。

**「常時稼働の軽負荷サーバー」が目的なら、まずは N100/N150 系を軸に検討する**のがおすすめです。逆に、動画のトランスコードやローカルLLMのように継続的な高負荷がかかる用途では、アイドル電力より「処理を速く終わらせて待機に戻る能力」の方が総消費電力量で有利になることもあります。

### 2. SSD・HDDの本数と種類

SATA HDD を複数台接続する NAS 的な使い方をすると、ディスクの回転維持だけで消費電力が数W単位で上乗せされます。目安は次のとおりです。

| ストレージ構成 | 追加される消費電力の目安 |
|---|---|
| NVMe SSD 1本 | +1〜3W |
| SATA SSD 1本 | +1〜2W |
| 3.5インチHDD 1台（回転時） | +5〜8W |
| 3.5インチHDD 4台（回転時） | +20〜32W |

純粋にアイドル電力を抑えたいなら、**NVMe SSD 一本構成がベスト**です。HDDを4台積んだNAS構成では、本体がどれだけ省電力でもディスク側で消費電力が跳ね上がります。大容量が必要な場合は、HDDのスピンダウン（一定時間アクセスがなければ回転停止）を設定できるかを確認してください。

### 3. ネットワークポートの数と速度

2.5GbEを2ポート搭載しているモデルは、ルーター兼用やNASとの直結に便利ですが、リンクアップしているだけで1ポートあたり1W前後を消費します。**使わないポートはBIOSやOS側で無効化する**と、わずかですが削減できます。

10GbE（特にSFP+の銅線トランシーバ）は消費電力が大きく、1ポートで2〜5W加算されることがあります。常時10GbEが必要でないなら、この点でも2.5GbEの方が自宅サーバー向きです。

## 実際に消費電力を下げる5つの設定

機種選びと同じくらい効くのが、購入後の設定です。同じ機体でも、設定次第で数W変わります。

### 1. BIOSでC-Stateを有効にする

CPUのアイドル時省電力機能です。**無効になっているとアイドル電力が3〜5W上がる**ことがあり、影響が最も大きい設定です。BIOSの Power Management 項目で、C-State（C6/C8以上まで）を有効にしてください。

### 2. 使わないデバイスを無効化する

Wi-Fi・Bluetooth・オーディオ・カードリーダー・未使用のLANポートは、有線運用のサーバーでは不要です。BIOSまたはOS側で無効化します。合計で1〜2W削減できることがあります。

### 3. Linuxでpowertopを使う

Linux 系OSなら、消費電力に影響する設定を自動で最適化できます。

```bash
sudo apt install powertop
sudo powertop --auto-tune     # 推奨設定を一括適用
```

`--auto-tune` は USB機器のオートサスペンドなども有効化するため、外付け機器を使っている場合は動作確認をしてから常用してください。起動時に自動適用したい場合は systemd のサービスとして登録します。

### 4. HDDのスピンダウンを設定する

データ用HDDを常時回す必要がないなら、一定時間で停止させます。

```bash
# 20分（240 = 5秒単位で48回 → 実装依存）アクセスがなければ停止
sudo hdparm -S 240 /dev/sda
```

ただし、**頻繁な起動停止はHDDの寿命を縮めます**。1日に何度もアクセスがある用途では、回しっぱなしの方が結果的に長持ちします。

### 5. 無駄なサービスを止める

デスクトップ環境（GUI）を入れたままのサーバーは、常にCPUを使い続けます。サーバー用途では**CUI（サーバー版OS）で運用する**のが基本です。

## 実測値は個体差・環境差があることに注意

同じCPUを搭載していても、電源アダプタの変換効率、SSDのメーカー、メモリの枚数、OSの省電力設定、室温によってアイドル電力は変動します。カタログの「アイドル○W」はあくまで目安です。

**正確に知りたいなら、ワットチェッカー（消費電力計）で測るのが確実です。** 2,000〜4,000円程度で入手でき、コンセントとの間に挟むだけで実際の消費電力が分かります。自宅サーバーを長く運用するなら、1台持っておくと設定変更の効果を数字で確認できるようになります。

測定するときのコツは、**電源投入直後ではなく、30分以上放置してから読む**ことです。起動直後はバックグラウンド処理が走っており、本来のアイドル値より高く出ます。

## よくある質問

**Q. アイドル10W以下を狙うと性能が足りなくなりませんか？**
用途によります。Pi-hole・Uptime Kuma・Vaultwarden・Home Assistant・Nextcloud 程度であれば N100/N150 クラスで十分です。足りなくなりやすいのは、Immich の初回インポート（機械学習処理）、Jellyfin の同時トランスコード、ローカルLLMの3つです。これらを想定するなら、10Wにこだわらず上位機を選んだ方が快適です。

**Q. スリープや自動シャットダウンで節電すべきですか？**
自宅サーバーは「いつでも応答すること」が価値なので、基本的には常時稼働が前提です。ただし、週末しか使わない検証環境などであれば、Wake-on-LAN で必要なときだけ起動する運用も有効です。

**Q. 電気代よりも本体価格を優先すべきケースは？**
3年以内に買い替える見込みがある場合や、消費電力の差が5W以内に収まる場合です。上の表のとおり、5W差の5年分は約1万円。本体価格差がそれ以上なら、安い方を選ぶ判断は合理的です。

**Q. UPS（無停電電源装置）を挟むと消費電力は増えますか？**
増えます。常時商用給電方式で数W、常時インバーター方式ではさらに大きくなります。ただし停電によるデータ破損のリスクと引き換えです。詳しくは [自宅サーバーのUPSおすすめと選び方](/articles/homelab-ups-osusume-2026/) をご覧ください。

## まとめ

- 電気代は `W × 24 × 365 ÷ 1000 × 31円` で計算できる。**10Wなら年間約2,716円**
- **省電力機どうしの差（6W対10W）は年1,000円程度**。本体価格差の方が大きいことが多い
- **20W超との差は決定的**。10Wと45Wでは5年で約4.8万円の開き
- HDDを積むと本体の省電力性より**ディスクの消費電力が支配的**になる
- 購入後は **C-State有効化・不要デバイス無効化・powertop** で数W下げられる
- 正確な値はワットチェッカーで測る。カタログ値は目安

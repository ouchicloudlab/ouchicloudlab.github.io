## はじめに：自宅サーバーを寝室に置きたいが、音が気になる

NASやミニPCで自宅サーバーを24時間稼働させたいけれど、置き場所がどうしても寝室しかない——というケースは珍しくありません。リビングに置くと家族の目に触れる、玄関やクローゼットは熱がこもる、となると消去法で寝室になりがちです。

問題は「動作音」です。昼間は気にならない程度のファン音でも、就寝中の静かな環境では驚くほど耳につきます。この記事では、ファン交換を中心に、距離・遮音・発音源対策の3方向から、寝室でも眠れる静音化の具体的な手順をまとめます。

## なぜ自宅サーバーは「うるさい」のか

自宅サーバーの騒音源は大きく3つに分けられます。

1. **ファンの風切り音・モーター音**：CPUファン、ケースファン、電源ユニットのファン
2. **HDDの回転・シーク音**：プラッタの回転音、ヘッドが動くカリカリ音
3. **振動の共振音**：筐体やラックに伝わった振動が増幅される「ビビリ音」

厄介なのは、これらが単独ではなく重なって聞こえる点です。ファン音自体は40dB程度でも、HDDの振動が棚に伝わって共振すると、体感的な不快感は数値以上に大きくなります。対策もこの3つに分けて考えると迷いません。

## 静音化の基本方針：距離・遮音・発音源対策

優先順位としては次の順番で検討するのが効率的です。

1. **距離を取る**：費用ゼロで最も効果が大きい
2. **発音源（ファン・HDD）を変える**：効果は大きいが手間とコストがかかる
3. **遮音・吸音する**：排熱との両立が難しく、最後の手段

### 距離による騒音減衰を計算してみる

音圧レベルは点音源からの距離に対して、理論上「距離が2倍になると6dB減衰する」という逆二乗則に従います。計算式は次の通りです。

```
L2 = L1 - 20 × log10(d2 / d1)
```

L1：基準距離での音圧レベル（dB）、d1：基準距離、d2：知りたい距離

仮に0.5mの位置で45dBのサーバーがあったとして、距離を変えた場合の目安は以下のようになります。

| 距離 | 計算 | 体感音圧レベルの目安 |
|---|---|---|
| 0.5m（机の上） | 基準値 | 約45dB |
| 1m | 45 − 20×log10(2) ≈ 45 − 6 | 約39dB |
| 2m（部屋の反対側） | 45 − 20×log10(4) ≈ 45 − 12 | 約33dB |
| 3m | 45 − 20×log10(6) ≈ 45 − 15.6 | 約29dB |

実際の部屋では壁や家具の反射があるためここまできれいには減衰しませんが、「ベッドからサーバーまでの距離を1mから2mに広げるだけで体感騒音はかなり下がる」という傾向は押さえておく価値があります。ラックを置く位置を壁際からベッドの対角線上に移すだけでも効果があります。

## ファン交換で静音化する手順

距離だけでは解決しない場合、発音源そのものを変えるのがファン交換です。

### ファンの選び方：口径・回転数・PWM対応

静音ファンを選ぶ際のチェックポイントは次の3つです。

- **口径はできるだけ大きく**：同じ風量なら、口径が大きいファンの方が低回転で済み静かです。40mmより60mm、60mmより80〜120mmが有利です。
- **回転数（RPM）と静圧・風量のバランス**：高静圧タイプはヒートシンク向け、高風量タイプはケース全体の排気向けです。狭いミニPC筐体では静圧重視を選びます。
- **PWM対応**：マザーボードやNASのファン端子がPWM制御に対応していれば、温度に応じて回転数を自動調整でき、アイドル時はほぼ無音にできます。

| ファンの種類 | 回転数の目安 | 騒音の目安 | 向いている用途 |
|---|---|---|---|
| 標準同梱ファン（小口径・高回転） | 3,000〜5,000RPM | 35〜45dB | 初期コスト重視・短時間稼働 |
| 静音タイプ（大口径・低回転） | 800〜1,500RPM | 15〜25dB | 24時間稼働・寝室設置 |
| PWM対応静音ファン | 300〜1,200RPM（可変） | 10〜25dB（負荷により変動） | 温度変化が大きい用途全般 |

### 交換手順の具体例

NASやミニPCのファン交換は、おおむね次の流れです。

1. 電源を落とし、電源ケーブルを抜いて放電（10分程度）を待つ
2. 筐体を開け、既存ファンのコネクタ形状（2pin/3pin/4pin PWM）とサイズをメモする
3. 同サイズ・同コネクタ、またはピッチ変換ケーブルで接続できる静音ファンを用意する
4. 取り付け向き（風の流れの矢印）を純正ファンと揃える
5. 仮組みで異音・干渉がないか確認してから本締めする

つまずきやすいのはコネクタ形状の違いです。サーバー向けマザーボードは4pin PWMが一般的ですが、NASの内蔵ファンは独自形状のことがあり、変換ケーブルが必要になるケースがあります。購入前に現物のコネクタ写真を控えておくと失敗が減ります。

### ソフトウェアでファン回転数を制御する

Linuxサーバーであれば、`lm-sensors`と`fancontrol`で温度に応じた回転数カーブを設定できます。

```bash
# センサーとファン制御ユーティリティを導入
sudo apt install lm-sensors fancontrol

# センサーを検出（対話式。基本はyesで進めてOK）
sudo sensors-detect

# 現在の温度とファン回転数を確認
sensors

# 対話形式でファンカーブを作成
sudo pwmconfig
```

`pwmconfig`で作成した設定は `/etc/fancontrol` に保存され、温度閾値ごとにPWM値（0〜255）を割り当てられます。アイドル時は低いPWM値に固定し、一定温度を超えたら段階的に上げる設定にすると、普段はほぼ無音で、高負荷時だけ回転数が上がる構成にできます。

IPMI対応のサーバーボードであれば、BMCのWeb管理画面や`ipmitool`でファンの状態を確認したり、ファンモードを変更できる場合もあります。

```bash
# ファンの回転数・状態を確認
ipmitool sdr type fan
```

ファンモードの変更には、メーカー・機種ごとに異なるベンダー独自のOEMコマンド（`ipmitool raw ...`）が使われます。値は機種によってまったく意味が異なるため、ネット上のコマンド例をそのまま流用せず、必ずメーカーのマニュアルやサポート情報に従ってください。特に自動ファン制御を無効化して手動の固定回転にすると、負荷が上がっても回転数が上がらず冷却不足になり、サーマルスロットリングや故障の原因になります。

## HDD・ストレージの騒音対策

ファンを静かにしても、HDDの回転音・シーク音が残ることがあります。対策は次の通りです。

- **NVMe/SATA SSDへの換装**：可動部がないため回転音・シーク音がゼロになります。システムドライブだけでもSSD化すると体感差は大きいです。
- **防振ゴムマウントの使用**：HDDを金属フレームに直付けせず、ゴムブッシュ経由で固定すると、筐体への振動伝達が減ります。
- **NASの「静音モード」設定**：多くのNASにはHDDのヘッド移動速度を落として静音性を優先するモードがあります。読み書き速度は多少落ちますが、家庭用途なら体感差はわずかです。
- **ディスク本数を減らす**：RAID構成を見直し、必要最小限の台数に絞るだけでも振動源が減ります。

## 筐体・設置場所の工夫

遮音ボックスや吸音材での対策は最後の手段です。密閉度を上げるほど熱がこもり、結果的にファンが高回転になって逆効果になることがあるためです。工夫する場合は次の順番で検討します。

1. 棚やラックの下に**防振ゴムシート**を敷いて設置面からの共振を抑える
2. 筐体と棚の間に**すき間**を作り、面接触による共振を避ける
3. どうしても音が気になる場合のみ、**通気孔を確保した吸音ボックス**を検討する（完全密閉は避ける）

## つまずきポイント

- **ファン交換後に異音が増えた**：取り付け向きが逆で風が逆流し、羽根が共振している場合があります。矢印表示を確認してください。
- **PWM制御が効かない**：マザーボード側のファン端子が固定回転（DC制御のみ）の場合、PWM対応ファンを挿しても最大回転数で回り続けることがあります。事前に端子の仕様を確認しましょう。
- **静音化したらサーマルスロットリングが発生**：風量を優先しすぎて静圧が不足し、ヒートシンクの温度が下がらないケースです。CPU温度をモニタリングしながら段階的に調整してください。
- **保証対象外になる**：NASやメーカー保証品のファンを分解交換すると、保証が無効になる場合があります。保証期間中の機種は事前に規約を確認してください。

## 静音化しなくていいケース・向いていない人

すべての人にファン交換が必要なわけではありません。次に当てはまる場合は、まず距離やレイアウトの見直しだけで十分なことが多いです。

- クローゼットや別室に設置場所を確保できる人（物理的に距離を取れるなら交換の優先度は下がります）
- もともとファンレス設計のミニPCを使っている人（追加対策の余地が少ない）
- 稼働時間が日中のみで、就寝中は電源を落とす運用にできる人
- DIYでの分解・配線変更に抵抗がある人（メーカー保証を優先し、設置場所の見直しだけで妥協するのも現実的な選択です）

## よくある質問（FAQ）

**Q. ファンを交換すると保証はどうなりますか？**
A. メーカー保証付きのNASや完成品PCは、分解した時点で保証対象外になることが一般的です。保証期間中は設置場所の見直しや防振対策を優先し、ファン交換は保証切れ後に検討するのが無難です。

**Q. PWM非対応のマザーボードでも静音ファンの効果はありますか？**
A. 回転数固定（DC制御）でも、大口径・低回転設計の静音ファンに交換するだけで、標準の小口径ファンより静かになるケースが多いです。ただし自動制御はできないため、常時同じ回転数で回り続けます。

**Q. HDDとSSD、どちらが静音化に効果的ですか？**
A. 容量単価はHDDが有利ですが、静音性だけを見ればSSDが圧倒的です。予算が許せば、頻繁にアクセスするシステム用途だけでもSSDに置き換えると体感差が大きく出ます。

**Q. 寝室に置く場合、最低限やるべきことは何ですか？**
A. 優先順位は「ベッドからの距離を取る」「防振ゴムで設置面の共振を抑える」「ファンをPWM対応の静音タイプに替える」の順です。コストをかけずにまず距離とレイアウトを見直すだけでも体感は変わります。

## まとめ

寝室に自宅サーバーを置く場合の静音化は、ファン交換だけに頼らず「距離」「発音源」「遮音」の3方向から組み合わせて考えるのが効率的です。特に設置距離の見直しは費用がかからず効果も大きいため、まず試す価値があります。そのうえでファンの口径・回転数・PWM対応を見直し、必要に応じてHDDの防振やSSD化を検討すると、就寝中も気にならないレベルまで静音化できます。

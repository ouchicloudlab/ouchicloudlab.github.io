「自宅サーバーって難しそう」——そう思って一歩を踏み出せない人は多いです。しかし2026年現在、**省電力で安いミニPCと、ブラウザだけで扱えるソフトウェア**が揃い、始めるハードルは大きく下がりました。

この記事では、自宅サーバーで何ができて、何が必要で、**実際にいくらかかるのか**を、計算過程まで含めて説明します。あわせて、あまり書かれない「やめておいた方がいいケース」も正直に書きます。

## 自宅サーバーとは？

自宅サーバー（homelab / おうちクラウド）とは、**自宅に置いた小さなコンピュータで、いつでも使えるサービスを動かす仕組み**のことです。クラウドサービスを月額で借りる代わりに、自分の機械で同じことを実現します。

具体的には、こんなことができます。

| やりたいこと | 使うソフト | 代替できる有料サービス |
|---|---|---|
| 写真の自動バックアップ | Immich | Googleフォト（有料プラン） |
| ファイル共有・同期 | Nextcloud | Google Drive / Dropbox |
| 家中の広告ブロック | Pi-hole / AdGuard Home | 各種広告ブロックアプリ |
| 動画・音楽の配信 | Jellyfin | 動画配信の月額サービス |
| パスワード管理 | Vaultwarden | パスワード管理サービス有料版 |
| スマート家電の統合 | Home Assistant | メーカー各社の純正アプリ |
| ローカルAIの実行 | Ollama | 生成AIのAPI従量課金 |

「月額課金の代替」と「自分のデータを自分で管理する」の2つが、始める理由の大半です。

## それでも、始めない方がいい人

先に正直なことを書きます。以下に当てはまる場合、自宅サーバーは**幸せになれない可能性が高い**です。

- **停止すると困るデータを、バックアップなしで置きたい人**：自宅サーバーはあなた以外に運用する人がいません。ディスクが壊れれば、データはそこで終わりです。クラウドの月額料金には「消えないように誰かが面倒を見ているコスト」が含まれています。
- **トラブル対応に時間を使いたくない人**：更新で壊れる、設定が飛ぶ、といったことは起きます。「調べて直すこと自体が面白い」と思えるかどうかが分かれ目です。
- **1〜2年で元を取りたい人**：後述しますが、金銭的な回収には時間がかかります。「安く済ませたい」だけが目的なら、期待とずれる可能性があります。

逆に、**仕組みを触ること自体が楽しい人**、**データを他社に預けたくない人**、**家族の写真や動画を大量に持っている人**には、はっきり向いています。

## 何が必要？（最小構成）

必要なのは主に3つだけです。

1. **本体（ミニPC）** … 心臓部。省電力なミニPCが定番
2. **ストレージ（SSD/HDD）** … データ保存用
3. **ネットワーク（自宅のルーター/LAN）** … 既存のもので十分

最初のうちは高価なNASや10GbEは不要です。**2〜3万円のミニPC1台**あれば、上に挙げたサービスのほとんどが動きます。

### メモリはいくつ必要か

初心者が最も迷うのがここです。目安は次のとおりです。

| メモリ | 動かせる範囲 |
|---|---|
| 8GB | 広告ブロック＋監視＋パスワード管理＋ファイル共有くらいまで |
| 16GB | 上記＋写真バックアップ（Immich）＋動画配信（Jellyfin）が現実的 |
| 32GB以上 | 仮想マシンを複数、ローカルLLM、本格的な検証環境 |

**迷ったら16GB**です。8GBで始めても動きますが、Immich のように機械学習を回すサービスを足した途端に足りなくなります。**後から増設できる機種かどうか**を購入前に確認しておくと、失敗のダメージが小さくなります。

> どのミニPCを選べばいいか迷ったら、用途別に比較した [自宅サーバー向けミニPCおすすめ5選](/articles/mini-pc-osusume-2026/) を参考にしてください。

## 費用の目安と、電気代の計算方法

### 初期費用

| 項目 | 目安 |
|---|---|
| 本体（入門ミニPC・16GB/512GB） | 25,000〜40,000円 |
| データ用SSD 1TB（追加する場合） | 10,000円前後 |
| バックアップ用外付けHDD 4TB | 10,000〜13,000円 |
| **合計（最小構成）** | **25,000〜60,000円** |

バックアップ用のディスクを「あとで買う」と決めると、たいてい買わないまま数か月が過ぎます。**最初の予算に組み込んでおくことを強くおすすめします。**

### 電気代は自分で計算できる

電気代の計算式はとても単純です。

```
1か月の電気代（円） = 消費電力(W) × 24時間 × 30日 ÷ 1000 × 電力量料金(円/kWh)
```

電力量料金を **31円/kWh** として計算すると、次のようになります。

| 平均消費電力 | 1か月の電気代 | 1年間 |
|---|---|---|
| 6W（超省電力ミニPC・軽負荷） | 約134円 | 約1,608円 |
| 10W（省電力ミニPC・標準） | 約223円 | 約2,678円 |
| 15W（サービスを多めに稼働） | 約335円 | 約4,018円 |
| 25W（高性能機・NAS併用） | 約558円 | 約6,696円 |
| 45W（中古デスクトップ流用） | 約1,004円 | 約12,053円 |

**ここが自宅サーバー選びの核心です。** 本体価格が2万円安い機種でも、消費電力が35W高ければ、年間で約9,500円の差がつきます。**2年ちょっとで価格差が逆転します。**

「余っている古いPCを使えばタダ」と考えがちですが、24時間稼働では**古い機械ほど高くつく**のが実情です。手元にあるPCで試すのは良い出発点ですが、常用すると決めたら省電力機への置き換えを検討してください。

> ※上記は電力量料金単価31円/kWhでの試算です。実際の請求額は契約プラン・燃料費調整額・再生可能エネルギー発電促進賦課金により変動します。

### 「元は取れるのか」を正直に計算する

仮に、Googleフォトの2TBプラン（月1,300円程度）を解約して Immich に移行したとします。

- 節約額：年間 15,600円
- かかる費用：本体35,000円＋バックアップHDD 12,000円＋電気代 年2,678円

初年度は 49,678円 − 15,600円 = **約34,000円の持ち出し**。2年目以降は年間12,922円の節約になるので、**回収完了はおよそ3年半後**です。

つまり、**純粋な金銭メリットだけで判断すると、あまり割に合いません**。それでも人気があるのは、複数のサービスをまとめて置き換えられること、容量を自分で決められること、そして「自分の環境を作る面白さ」があるからです。ここを理解したうえで始めると、期待値のズレが起きません。

## 始め方の手順（5ステップ）

### ステップ1：ミニPCを用意する

省電力なミニPCを1台用意します。メモリは16GB以上、システム用SSDは256GB以上あると安心です。

購入したら、**まず設置場所を決めてください**。24時間動く機械なので、以下を満たす場所が必要です。

- 熱がこもらない（密閉した棚の奥はNG）
- 静かさが気にならない（寝室は避けたほうが無難）
- 有線LANが届く（Wi-Fi運用も可能ですが、安定性で有線を推奨）

### ステップ2：IPアドレスを固定する

見落とされがちですが、**最初にやるべき設定**です。ルーターのDHCP設定で、サーバーのMACアドレスに対して常に同じIPを割り当てます（DHCP固定割当）。

これをやらないと、ある日突然IPが変わってすべてのサービスに繋がらなくなります。特に Pi-hole をDNSとして使う場合、**家中のインターネットが止まる**ため必須です。

### ステップ3：土台のOSを入れる

選択肢は2つあります。

- **Proxmox VE を入れる**：1台の中に複数の仮想マシン・コンテナを作れます。環境を丸ごとスナップショットで保存でき、失敗しても数秒で戻せるのが最大の利点。管理画面はブラウザから使えます。
- **Ubuntu Server などを直接入れて Docker だけ使う**：構成がシンプルで、リソースの無駄が少ない。

**初心者には Proxmox をおすすめします。** 理由は「壊しても戻せる」からです。設定をいじって起動しなくなっても、スナップショットから戻せば数秒で復旧します。この安心感が、学習速度を大きく変えます。

導入手順は [Proxmox入門｜ミニPC1台で始める自宅仮想化](/articles/proxmox-nyumon-minipc/) で解説しています。

### ステップ4：Dockerでサービスを動かす

実際のサービスは **Docker**（コンテナ）で動かすのが主流です。設定ファイル（`compose.yaml`）を1つ書くだけで、Nextcloud や Pi-hole が立ち上がります。

最初の1個は **Pi-hole か AdGuard Home** がおすすめです。導入して数分で「広告が消えた」と体感でき、モチベーションが続きます。

> 何を動かすか迷ったら [Dockerで動かす自宅サービス10選](/articles/docker-self-hosting-10/) に、必要メモリと導入順序をまとめています。

### ステップ5：バックアップを設定する（省略しない）

**ここまでやって初めて「サーバー」になります。** 最低限、以下の2つを決めてください。

1. **何を守るか**：各サービスのデータディレクトリ（`/srv/docker/` 以下にまとめておくと楽です）
2. **どこへコピーするか**：外付けHDD、別のPC、またはクラウドストレージ

Linux なら `rsync` を cron で回すだけで十分です。

```bash
# 毎日 4:00 に外付けHDDへ差分同期する例
0 4 * * * rsync -a --delete /srv/docker/ /mnt/backup/docker/
```

「RAIDを組んでいるから安心」は誤解です。**RAIDはディスク故障には強いですが、誤って削除したファイルは同時に消えます。** 別の場所へのコピーが必要です。

### （任意）ステップ6：外からアクセスできるようにする

外出先からも使いたい場合は、**Tailscale**（メッシュVPN）を入れるのが2026年の定番です。ルーターのポート開放をせずに、安全に自宅サーバーへ接続できます。

**ポート開放による直接公開はおすすめしません。** 設定を1つ間違えると、世界中からアクセス可能な状態になります。詳しくは [Tailscaleで自宅サーバーに外部から安全にアクセスする設定方法](/articles/tailscale-home-server-remote-access-2026/) をご覧ください。

## 初心者がつまずきやすい5つの点

1. **IPを固定していない** … ある日突然すべて繋がらなくなる。最初にやる。
2. **バックアップがない** … RAIDはバックアップではない。別媒体へコピーする。
3. **ポート開放で直接公開してしまう** … VPN（Tailscale）を使う。
4. **メモリ不足で後悔** … 8GBで始めて Immich を入れた途端に足りなくなる典型例。
5. **消費電力を見ずに古いPCを常用** … 年1万円以上の差がつくことがある。

## よくある質問

**Q. 電気代以外にランニングコストはかかりますか？**
基本的にはかかりません。強いて言えば、数年後のディスク交換費用（HDDの寿命は概ね5年前後）と、故障時の買い替え費用です。ドメインを取得して外部公開する場合は年間1,000〜2,000円程度が加わります。

**Q. 24時間つけっぱなしで火事が心配です。**
消費電力10W程度の機器は、常時稼働する家電（冷蔵庫やルーター）と比べても小さな負荷です。ただし、**タコ足配線を避ける**、**ホコリの溜まる場所に置かない**、**排気口を塞がない**の3点は守ってください。雷や停電が心配な場合は [UPS（無停電電源装置）](/articles/homelab-ups-osusume-2026/) の導入も検討する価値があります。

**Q. Raspberry Pi ではダメですか？**
動きます。消費電力は最も低く、入門機として優秀です。ただし2026年現在、**省電力ミニPCの価格が下がった**ことで、x86ソフトの互換性・処理速度・拡張性を考えると、ミニPCの方が総合的に扱いやすい場面が増えています。Immich や Jellyfin のような重めのサービスを想定するなら、ミニPCが無難です。

**Q. 賃貸でも問題ありませんか？**
機器を置くだけであれば問題ありません。壁に穴を開けるLAN配線工事などを行う場合は、事前に管理会社へ確認してください。

## まとめ

- 自宅サーバーは「月額課金の代替」と「データを自分で管理する」ための仕組み
- 最小構成は **ミニPC＋SSD＋バックアップ用HDD**、25,000〜60,000円程度
- 電気代は `W × 24 × 30 ÷ 1000 × 31円` で計算できる。10W なら月223円
- **金銭的な回収には3年前後かかる**。面白さと自由度に価値を感じるかが判断基準
- 最初にやるべきは **IP固定** と **バックアップ設定**

まずは安いミニPC1台から、小さく始めてみるのがおすすめです。次のステップとして、機材選びは [ミニPCおすすめ比較](/articles/mini-pc-osusume-2026/) をどうぞ。

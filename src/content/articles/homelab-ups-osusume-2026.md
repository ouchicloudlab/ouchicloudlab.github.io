自宅サーバーやNASを24時間動かしていると、避けて通れないのが **停電・瞬電（一瞬の電圧低下）** のリスクです。稼働中に電源が突然切れると、書き込み途中のデータが失われるだけでなく、最悪の場合ファイルシステムそのものが破損します。これを防ぐのが **UPS（無停電電源装置）** です。

UPSは「大きな充電池付きの電源タップ」のようなもの。停電した瞬間にバッテリー給電へ切り替わり、その間に**サーバーを安全に自動シャットダウン**させることでデータを守ります。

この記事では、必要な容量の**計算方法**から、自動シャットダウン連携の**具体的な設定**、そして買った後に必ず来る**バッテリー交換**まで含めて解説します。

## そもそもUPSは必要か？

正直に書くと、**全員に必要というわけではありません**。判断基準は「電源が突然切れたときに困るか」です。

| 状況 | UPSの必要度 |
|---|---|
| ZFS/Btrfs でNASを運用、書き込みが多い | **高い**（ファイルシステム破損のリスクが大きい） |
| 家族の写真を預かる唯一の保管場所になっている | **高い** |
| HDDを複数台搭載したRAID構成 | **高い**（再構築中の停電は致命的） |
| Pi-hole だけを動かしている | 低い（DNSが数分止まるだけ） |
| バックアップが別途しっかり取れている | 中（復旧できるなら被害は時間だけ） |
| 落雷や停電が多い地域に住んでいる | **高い** |

特に注意したいのが**瞬電**です。1秒未満の電圧低下でもサーバーは再起動しますが、これは年に何度か起こり得ます。「停電した記憶はないのに、サーバーの稼働時間がリセットされている」という場合、瞬電が起きています。

## 必要な容量を計算する

UPS選びで最も重要なのが容量です。手順は3ステップです。

### ステップ1：つなぐ機器の消費電力を合計する

一般的な自宅サーバー構成の例です。

| 機器 | 消費電力の目安 |
|---|---|
| 省電力ミニPC（アイドル） | 8〜15W |
| 2ベイNAS本体 | 10〜20W |
| 3.5インチHDD ×2台 | 10〜16W |
| ネットワークスイッチ（8ポート） | 5〜10W |
| ルーター／ONU | 10〜15W |
| **合計** | **43〜76W** |

**ルーターとONUをUPSに繋ぐかどうか**は重要な判断です。繋いでおけば停電中もネットワークが生き、外出先から状況を確認したりシャットダウンを指示したりできます。消費電力も小さいので、繋いでおくことをおすすめします。

一方、**モニター・プリンター・レーザー機器は繋がないでください**。消費電力が大きく、バッテリーをすぐに使い切ります。

### ステップ2：定格W数が合計の2倍以上のモデルを選ぶ

UPSの容量はVA（皮相電力）とW（有効電力）で表記されます。**重要なのはWの方**です。VAだけが大きく表示されている製品もあるので、必ずW表記を確認してください。

合計75Wの構成なら、**定格150W以上**のモデルが目安です。2倍を見る理由は次の2つです。

- 起動時の突入電流や、負荷変動に耐えるため
- **バッテリーが劣化しても、必要な給電時間を確保するため**（ここが本命）

### ステップ3：必要な給電時間を確認する

必要なのは「シャットダウンが完了するまでの時間」です。目安は次のとおりです。

| 構成 | シャットダウンに必要な時間 |
|---|---|
| ミニPC1台（SSD） | 30秒〜1分 |
| NAS（HDD 2台・RAID1） | 1〜3分 |
| 仮想マシンを複数動かしたホスト | 3〜10分 |

つまり、**十数分の給電能力があれば十分**です。「1時間もたせたい」という要件は、自宅サーバーではほとんど必要ありません。長時間の稼働継続を目指すと、UPSの価格と設置スペースが跳ね上がります。

## 「正弦波」か「矩形波」か

- **正弦波（サイン波）**：コンセントと同じ波形。NASや高効率電源（アクティブPFC）との相性が良く、トラブルが少ない。**基本はこちらを推奨**
- **矩形波（短形波）**：安価だが、アクティブPFC電源と組み合わせると**バッテリー給電に切り替わった瞬間に機器が落ちる**ことがある

矩形波モデルの相性問題は、**停電が起きて初めて発覚する**のが厄介な点です。「UPSを付けていたのに落ちた」というトラブルの多くはこれです。ミニPCのACアダプタ程度なら問題ないことが多いものの、**NASや自作PCの電源ユニットを繋ぐなら正弦波を選んでください。**

## 自動シャットダウン連携の設定

UPSの真価は「停電時にサーバーを自動で安全に終了させる」点にあります。**バッテリーで粘ることではなく、安全に終わらせることが目的**です。

### 完成品NAS（Synology / QNAP）の場合

USBケーブルでUPSと接続すれば、管理画面から設定できます。Synology なら「コントロールパネル → ハードウェアと電源 → UPS」で有効化し、**「バッテリーモードに入ってから何分後にシャットダウンするか」**を指定します。

複数台を守る場合、NASを「UPSサーバー」にして、他の機器をネットワーク経由で連動させることもできます。

### Linux（Proxmox / Ubuntu）の場合

**NUT（Network UPS Tools）** が定番です。

```bash
sudo apt install nut
# 接続されているUPSを検出
sudo nut-scanner -U
```

検出結果を `/etc/nut/ups.conf` に記載し、`upsmon` の設定でシャットダウン条件を決めます。

```
# /etc/nut/upsmon.conf の例
# バッテリー残量が低下したら（LOWBATT）シャットダウンする
MONITOR myups@localhost 1 upsmon ここにパスワード master
```

設定後は必ず**テストしてください**。UPSのコンセントを実際に抜いて、想定どおりシャットダウンが始まるかを確認します。**設定したつもりで動いていなかった、というのが最も多い失敗**です。

### 設定時に決めておくべき2つの値

1. **何分後にシャットダウンを始めるか**：短すぎると瞬電のたびに落ちます。**2〜5分程度の猶予**を置くと、短時間の停電では止まらずに済みます。
2. **電源復帰時に自動起動するか**：ミニPCのBIOSで「Restore on AC Power Loss → Power On」を設定しておかないと、停電から復帰しても手動で電源を入れるまで起動しません。**外出中の停電では致命的**なので必ず設定してください。

## バッテリーは消耗品：2〜5年で交換が必要

UPSで見落とされがちなのがランニングコストです。**内蔵バッテリーは2〜5年で寿命**を迎えます。

| 項目 | 目安 |
|---|---|
| バッテリー寿命 | 2〜5年（設置環境の温度に大きく依存） |
| 交換バッテリー価格 | 5,000〜15,000円程度 |
| UPS自体の消費電力 | 常時商用給電方式で 3〜8W |

**UPS自体も電気を消費する**点は覚えておいてください。5Wなら年間約1,358円（31円/kWh換算）です。

寿命を延ばすコツは**温度管理**です。鉛蓄電池は高温で急速に劣化するため、直射日光の当たる場所や、機器の排気が直接当たる場所は避けてください。目安として、周囲温度が10℃上がると寿命はおよそ半分になると言われています。

交換用バッテリーが単体で入手できるメーカー（APC・オムロンなど）を選んでおくと、**本体ごと買い替えずに済みます**。安価な製品では交換バッテリーが流通しておらず、結局本体を買い直すことになる場合があります。

## 導入後にやること（チェックリスト）

1. **実際にコンセントを抜いてテストする**（設定が効いているかの確認）
2. **BIOSで電源復帰時の自動起動を有効化する**
3. **UPSの警告を通知として受け取れるようにする**（メール／LINE等）
4. **バッテリー交換時期をカレンダーに登録する**（購入から3年後など）
5. **年に1回はテストを繰り返す**（バッテリー劣化の確認）

## よくある質問

**Q. UPSがあれば停電中もずっと使い続けられる？**
いいえ。UPSは「安全にシャットダウンするための数分〜十数分」を稼ぐ装置です。長時間の連続稼働が目的ではありません。長時間稼働を目指すと、必要な容量と価格が跳ね上がります。

**Q. 電源タップ型の安いもので代用できない？**
雷ガード付きタップでは瞬電・停電時の給電はできません。データ保護が目的ならバッテリー内蔵のUPSが必要です。逆に、**雷サージ対策だけが目的なら雷ガードタップで足ります**。

**Q. UPSを付ければバックアップは不要？**
いいえ。UPSは電源トラブルからは守れますが、ディスク故障・誤削除・ランサムウェアには無力です。バックアップとUPSは目的が異なります。**優先順位はバックアップが先**です。

**Q. どのくらいの頻度で買い替える？**
本体は10年近く使えることもありますが、**内蔵バッテリーは2〜5年で劣化**します。UPSが警告を出したら早めに交換バッテリーを用意してください。劣化したバッテリーは、いざという時に数十秒しか持ちません。

**Q. 雷が直撃したらUPSで守れますか？**
直撃雷は防げません。UPSやサージプロテクタが防げるのは、近隣への落雷による誘導雷（電線を伝わってくる過電圧）までです。雷が多い地域では、外出時や雷雨時にコンセントを抜くのが最も確実です。

## まとめ

- UPSの目的は**長時間稼働ではなく、安全にシャットダウンする時間を稼ぐこと**
- 容量は「接続機器の合計消費電力の**2倍以上のW数**」が目安
- **正弦波モデルを選ぶ**。矩形波はNASや自作PC電源との相性問題が起こり得る
- **自動シャットダウン連携の設定とテストまでやって初めて意味がある**
- バッテリーは2〜5年の消耗品。交換品が入手しやすいメーカーを選ぶ
- **UPSはバックアップの代わりにはならない**

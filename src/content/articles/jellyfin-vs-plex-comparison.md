## 自宅メディアサーバーとは何か

自宅にあるNASやミニPCに動画・音楽・写真を集約し、テレビやスマホからいつでも視聴できるようにする仕組みが「自宅メディアサーバー」です。NetflixのようなUIで自分のコレクションを整理できるのが魅力で、代表的なソフトが**Jellyfin**と**Plex**です。この記事では両者の違いと、初心者にどちらが向いているかを整理します。

## 最重要ポイント：トランスコードを理解する

メディアサーバー選びで、**性能面の話はほぼすべてここに集約されます**。ここを理解しておくと、必要な機材が自分で判断できるようになります。

### ダイレクト再生とトランスコードの違い

- **ダイレクト再生（Direct Play）**：サーバーはファイルをそのまま送るだけ。**CPU負荷はほぼゼロ**
- **トランスコード**：再生側が対応していない形式のとき、サーバーが**リアルタイムで変換しながら**配信する。CPU/GPUを大量に消費

つまり、**「再生側が対応している形式で保存しておけば、非力なサーバーでも問題なく動く」**ということです。逆に、変換が必要な状況を作ってしまうと、どんなに高性能なサーバーでもすぐに限界が来ます。

### トランスコードが発生する主な条件

| 条件 | 説明 |
|---|---|
| コーデック非対応 | 再生側が HEVC(H.265) や AV1 に非対応 |
| 字幕の焼き込み | **PGS/VOBSUB などの画像字幕**は映像に焼き込む必要があり、必ず変換が発生 |
| 帯域制限 | 外出先からの視聴で、画質を落として配信する場合 |
| 音声形式非対応 | TrueHD/DTS-HD を再生できない端末（この場合は音声のみ変換で軽い） |

**見落とされがちなのが字幕**です。映像・音声が対応形式でも、画像ベースの字幕を表示しようとした瞬間にフル変換が始まります。字幕はできるだけ**テキスト形式（SRT）**で用意しておくと、変換を回避できます。

### 必要な処理能力の目安

ハードウェアトランスコード（Intel Quick Sync など）を使った場合の、同時変換できるストリーム数の目安です。

| 環境 | 1080p 同時変換 | 4K → 1080p 同時変換 |
|---|---|---|
| Intel N100/N150（第12世代相当のiGPU） | 5〜8本 | 2〜3本 |
| Core i5（第10世代以降） | 8〜15本 | 3〜5本 |
| **CPUのみ（ハードウェア支援なし）** | **1〜2本** | **ほぼ不可** |
| ARM系NAS（エントリーモデル） | 0〜1本 | 不可 |

**ハードウェアトランスコードの有無で10倍近い差**が出ます。メディアサーバーを主目的にするなら、**Intel の内蔵GPU（Quick Sync）を搭載した機種**を選んでください。これはミニPC選びで数少ない「明確にIntelが有利な用途」です。

なお、Jellyfin でのハードウェアアクセラレーションは、コンテナに `/dev/dri` を渡す設定が必要です。Plex では**Plex Pass（有料）が必須**という違いがあります。

## ファイル整理の作法（ここで9割決まる）

導入後に「映画が認識されない」「シーズンがバラバラになる」という相談が非常に多いのですが、原因のほとんどは**ファイル名とフォルダ構成**です。両ソフトとも、ファイル名からメタデータを自動取得する設計になっています。

推奨される構成は次のとおりです。

```
Movies/
  作品名 (2024)/
    作品名 (2024).mkv

TV Shows/
  番組名 (2023)/
    Season 01/
      番組名 - S01E01.mkv
      番組名 - S01E02.mkv
```

ポイントは3つです。

1. **年号を括弧付きで入れる**（同名作品の誤認識を防ぐ）
2. **シーズンとエピソードは `S01E01` 形式**で統一する
3. **映画は1作品1フォルダ**にする

この規則を守るだけで、ポスター画像やあらすじが自動で取得され、見た目が一気に「それらしく」なります。逆に、ここが雑だと後から直すのが非常に面倒です。**最初にルールを決めてから取り込んでください。**

## 動作させるハードウェアの目安

視聴人数が少なく、ダイレクト再生で済むなら、省電力ミニPCでも十分動きます。目安をまとめます。

| 用途 | 推奨構成 |
|---|---|
| 家庭内で1〜2人、ダイレクト再生中心 | N100級ミニPC＋8GB |
| 家族4人、時々トランスコード | Intel第12世代以降のiGPU搭載機＋16GB |
| 4K素材を外出先へ配信 | Core i5以上＋16GB＋上り回線の帯域確認 |
| ARM系エントリーNAS | ダイレクト再生のみに限定する前提で |

**メモリよりもGPU（iGPU）世代の方が効きます。** メモリは8GBあれば足り、16GBあれば他のサービスと同居できます。

ストレージについては、動画は容量を大きく消費します（4K映画1本で20〜60GB）。**HDDで容量を確保し、システムとメタデータはSSDに置く**構成が定番です。動画の連続読み出しはHDDの得意分野なので、ここにSSDを使う必要はありません。

## 外出先から視聴するときの帯域

自宅の**上り（アップロード）速度**が上限になります。

| 画質 | 必要な上り帯域の目安 |
|---|---|
| 1080p | 8〜12Mbps |
| 4K（変換なし） | 40〜80Mbps |
| 1080pに落として配信 | 5〜10Mbps |

一般的な光回線の上りは100Mbps〜1Gbps程度なので1〜2本なら問題ありませんが、**上りが遅い回線（一部のケーブルテレビ回線など）では、4Kのそのまま配信は難しい**ことがあります。

Plex はアカウント登録するだけでリモートアクセスが設定されますが、Jellyfin は自分で経路を用意する必要があります。**ポート開放ではなく [Tailscale](/articles/tailscale-home-server-remote-access-2026/) を使うのが安全で簡単**です。

## 何を基準に選ぶべきか

### とにかく無料で、プライバシーも重視したい人

**Jellyfin** がおすすめです。アカウント登録すら不要で、すべて自分のサーバー内で完結します。メタデータ取得やトランスコードもローカルで処理されます。

**ハードウェアトランスコードが無料で使える**点は、Plex（Plex Pass必須）に対する明確な優位点です。一方、リモートアクセスは自分で構成する必要があります。

### 設定を簡単に済ませて、家族にも使ってもらいたい人

**Plex** が向いています。アカウントを作成するだけでリモートアクセスが自動設定され、スマートテレビやゲーム機など対応デバイスも非常に豊富です。

**「家族が自分で操作できるか」を重視するなら Plex**です。テレビのアプリストアから入れてログインするだけ、という手軽さは実際の運用で効いてきます。ただし、ハードウェアトランスコード・オフライン同期・イントロスキップなどは Plex Pass（有料）が必要です。

### ライブTVやDVR機能も使いたい人

**Emby** はライブTV録画機能が比較的しっかりしており、チューナーと組み合わせた運用に向いています。ただし Jellyfin は Emby からフォークして生まれた経緯があり、UIの使い勝手は非常に近いため、無料で同等の体験を求めるなら Jellyfin を先に試す価値があります。

## 導入後によくあるトラブル

- **再生がカクつく／止まる** → トランスコードが発生していないか確認。管理画面の再生情報で「Direct Play」か「Transcode」かが分かります
- **ライブラリに出てこない** → ファイル名の規則を確認。前述の命名ルールを守る
- **テレビのアプリで一部の動画だけ再生できない** → そのテレビが対応していないコーデック。ファイル側を変換しておくのが根本解決
- **サーバーのCPUが張り付く** → ハードウェアアクセラレーションが有効になっていない可能性が高い

## よくある質問

**Q. JellyfinとPlexを同じサーバーで併用できますか？**
できます。ポートが異なるため共存可能で、同じライブラリフォルダを両方に読ませることもできます。**まず両方入れて比較するのが最も確実**です。

**Q. Plex Pass は買う価値がありますか？**
ハードウェアトランスコードを使いたいなら実質必須です。逆に、ダイレクト再生中心で家庭内利用なら無料版で困りません。**無料でハードウェア支援を使いたいなら Jellyfin** という判断になります。

**Q. スマートテレビで見られますか？**
Plex は対応アプリが多く、多くのスマートTVやゲーム機で公式アプリが提供されています。Jellyfin は公式アプリの対応範囲がやや狭いものの、Fire TV Stick や Android TV では問題なく使えます。**手持ちのテレビで動くか**が実質的な判断材料になります。

**Q. 電気代はどれくらいかかりますか？**
ダイレクト再生中心なら、アイドル時とほとんど変わりません（10W級で月223円程度）。トランスコードが走ると一時的に30〜50Wまで上がりますが、視聴時間分だけなので影響は限定的です。

**Q. 録画したテレビ番組も見られますか？**
形式が対応していれば再生できます。日本の地上デジタル放送の録画データには保護がかかっている場合があり、そのままでは扱えないことがあります。ご利用の環境と、各サービスの利用条件をご確認ください。

## まとめ

- **性能の話はトランスコードにほぼ集約される**。ダイレクト再生なら非力な機材でも十分
- **Intel の Quick Sync（iGPU）の有無で処理能力が10倍近く変わる**
- **画像字幕（PGS）はフル変換を誘発する**。テキスト字幕（SRT）を使う
- ファイル名は `作品名 (年)` と `S01E01` の規則を守る。**後から直すのは大変**
- **無料＋ハードウェア支援 → Jellyfin**、**手軽さ＋家族の使いやすさ → Plex**、**ライブTV → Emby**
- リモート視聴は自宅の**上り帯域**が上限。Jellyfin なら Tailscale と組み合わせる

まずは手持ちの機材に Jellyfin を導入してみて、物足りなさを感じたら Plex を検討するのが失敗の少ない進め方です。動かす母艦の選び方は [自宅サーバー向けミニPCおすすめ5選](/articles/mini-pc-osusume-2026/) を参考にしてください。

## Wi-Fi 7ルーター、自宅サーバーがある家では何を見るべきか

Wi-Fi 7（IEEE 802.11be）対応のルーターが1万円前後の価格帯から手に入るようになり、買い替えを考える人が増えています。ただ、自宅サーバーやNASを置いている家では、カタログの「最大◯Gbps」や「10G対応」だけで選ぶと、期待したほど速くならないことがあります。

理由は2つあります。1つは、**Wi-Fi 7の機能はスマホやPCの側も対応していないと効かない**こと。もう1つは、**ルーターの「10G対応」は多くの場合インターネット側（WAN）の話で、NASやサーバーをつなぐ宅内側（LAN）は1Gbpsのままのことがある**という点です。

この記事では、Wi-Fi 7で何が変わるかを整理したうえで、5製品のポート構成を比べ、何を有線にして何を無線にするかの線引きまでまとめます。スイッチやNICの選び方は [家庭内LANを2.5GbE化する機材まとめ](/articles/home-2-5gbe-network-2026/) で扱っているため、ここではルーターと無線の判断に絞ります。

## Wi-Fi 7で変わること（規格の要点）

Wi-Fi 7の主な変更点は次の4つです。表の数値はいずれも規格上の値で、家庭で出る速度ではありません。

| 項目 | Wi-Fi 6／6E | Wi-Fi 7 | 効く条件 |
|---|---|---|---|
| 最大チャネル幅 | 160MHz | 320MHz（6GHz帯のみ） | ルーターと端末の両方が6GHz・320MHzに対応 |
| 変調方式 | 1024QAM（1シンボル10ビット） | 4096QAM（1シンボル12ビット） | 電波がかなり強い近距離に限られる |
| 複数帯域の同時利用 | なし（1つの帯域に接続） | MLO（Multi-Link Operation） | 端末側もMLOに対応 |
| 規格上の最大速度 | 約9.6Gbps | 約46Gbps | 家庭用機器では実現しない理論上の上限 |

### 320MHz幅は「6GHz帯があって、端末も対応していれば」

チャネル幅は道路の車線数のようなもので、160MHzから320MHzに広がると、理論上の速度はおおむね2倍になります。ただし320MHz幅を使えるのは6GHz帯だけです。今回の5製品でいえば、6GHz帯と320MHz幅に対応するのはトライバンドのWXR9300BE6PとRT-BE92Uです（WXR9300BE6Pは商品ページ、RT-BE92Uはメーカーの仕様表で確認）。デュアルバンド（5GHz＋2.4GHz）の3機種では、Wi-Fi 7でも最大160MHz幅になります。

また、日本で使える6GHz帯は幅が限られているため、320MHz幅を取れるチャンネルの選択肢は多くありません。近所に同じ帯域を使う機器が増えると、混雑を避ける余地も小さくなります。

### 4096QAMは近距離向けの上積み

1回の電波に載せる情報量を10ビットから12ビットに増やす技術で、理論上の伸びは約2割です。電波が強く雑音の少ない状態でしか使われないため、同じ部屋の近距離では効いても、壁を隔てた部屋では従来の変調に落ちます。

### MLOは速度より「途切れにくさ」に効く

MLOは、5GHzと6GHzのように複数の帯域を1台の端末が同時に、または切り替えながら使う仕組みです。一方の帯域が混んだときにもう一方へ逃げられるため、速度の上積みよりも、遅延のばらつきを抑える効果が期待されています。WSR6500BE6Pの商品ページにも「2バンド同時モード／2バンド切り替えモード」があり、端末側の対応も必要と書かれています。

### 端末が非対応なら、Wi-Fi 6として動くだけ

ここが買い替えで一番大事な点です。Wi-Fi 7ルーターにWi-Fi 6の端末をつなぐと、通信はWi-Fi 6の方式で行われます。320MHz幅も4096QAMもMLOも、端末が対応していなければ使われません。Wi-Fi 7に対応するのは比較的新しいスマホ・ノートPCの一部で、Windowsでは Windows 11 の24H2以降で対応が入ったとされます。PCの場合は、OSとWi-Fiモジュール、ドライバーのすべてが揃って初めてWi-Fi 7で接続します。

自分の端末がどの規格でつながっているかは、次のコマンドで確認できます。

```powershell
# Windows：「無線の種類」が 802.11be なら Wi-Fi 7、802.11ax なら Wi-Fi 6/6E
netsh wlan show interfaces
```

```bash
# Linux：接続中の周波数とリンク速度（tx bitrate）を表示
iw dev wlan0 link   # wlan0 の部分は iw dev で確認したインターフェース名に置き換える
```

## 自宅サーバー視点の核心：「10G対応」はどのポートの話か

ルーターには、光回線の終端装置（ONU）につなぐWAN（バッファローの表記ではINTERNET）ポートと、宅内の機器をつなぐLANポートがあります。**NASとPCの間の通信はLAN側で完結し、WANポートを通りません。** つまり、WANが10Gbpsでも、NASをつないだLANポートが1Gbpsなら、NASとの転送は1GbEの速度が上限です。

今回の5製品のポート構成を、商品ページとメーカーの仕様表で確認できた範囲で並べます。

| 製品 | 無線（帯域） | WAN（INTERNET） | LAN | 1Gbps超のLANを作れるか |
|---|---|---|---|---|
| Archer BE220 | デュアル（5GHz・2.4GHz） | 1Gbps×1 | 1Gbps×4 | 作れない |
| Archer BE450 | デュアル（5GHz・2.4GHz） | 10Gbps と 2.5Gbps が WAN/LAN 兼用 | 兼用ポートのうちWANにしなかった方＋1Gbps×3 | 作れる（片方をWAN、片方をLANに） |
| WSR6500BE6P | デュアル（5GHz・2.4GHz） | 2.5Gbps | 1Gbps×3 | 作れない |
| WXR9300BE6P | トライ（6GHz・5GHz・2.4GHz） | 10Gbps | 1Gbps×4（「INTERNETポートのみ10Gbps対応」と明記） | 作れない |
| RT-BE92U | トライ（6GHz・5GHz・2.4GHz） | 10Gbps と 2.5Gbps が WAN/LAN 兼用 | 兼用ポートのうちWANにしなかった方＋2.5Gbps×3 | 作れる（10ギガ回線なら2.5Gbps×4をLANに） |

この表から読み取れるのは、**ルーター単体でNAS用の高速LANを作れるのは、今回の5製品ではBE450とRT-BE92U**ということです。BE450で10ギガ回線を使う場合は、10GbpsポートをWANに、2.5GbpsポートをNASやメインPC向けのLANに割り当てます。RT-BE92Uは10GbpsポートをWANにしても2.5GbpsのLANが4つ残るため、NASとPCを複数台つなぐ構成に向きます（ポートの割り当て方は設定画面とマニュアルで確認してください）。

WXR9300BE6Pの10GbpsのINTERNETポートが無駄になるわけではありません。10ギガ回線の帯域を、6GHz帯でつながる複数の無線端末で分け合う使い方では効きます。ただ、有線でつないだ1台のPCが出せるインターネット速度は、そのLANポートの速度で止まります。

ルーターのLANが1Gbpsのままでも、NASやPCの間を速くする方法はあります。ルーターの1GbpsのLANポートから2.5GbEスイッチへつなぎ、NASとPCをそのスイッチにまとめれば、NASとPCの間は2.5GbEで通信し、インターネットへ出る分だけがルーターを通ります。ルーターを買い替えるより、スイッチを足すほうが安く済むことも多い構成です。

## 計算例：10GBの動画をNASからコピーすると何秒か

接続方式による差を、10GB（10,000MB）のファイルをNASからPCへコピーする時間で比べます。有線は理論帯域で、無線は仮の実効速度で計算しています。

- 有線1GbE：`1,000Mbps ÷ 8 ＝ 125MB/s` → `10,000 ÷ 125 ＝ 80秒`
- 有線2.5GbE：`2,500Mbps ÷ 8 ＝ 312.5MB/s` → `10,000 ÷ 312.5 ＝ 32秒`
- Wi-Fi 7（2ストリーム・160MHz、規格値2,882Mbps）：実効を規格値の50%と仮定 → `2,882 × 0.5 ÷ 8 ≒ 180MB/s` → 約56秒
- Wi-Fi 6（2ストリーム・160MHz、規格値2,402Mbps）：同じく50%と仮定 → `2,402 × 0.5 ÷ 8 ≒ 150MB/s` → 約67秒
- 離れた部屋のWi-Fi：実効300Mbpsと仮定 → `300 ÷ 8 ＝ 37.5MB/s` → 約267秒

無線の「規格値の50%」は説明のための仮の値です。実際の実効速度は、距離、壁、近所の電波、同時に通信している端末の数で大きく変わり、もっと低くなることも珍しくありません。有線も実際にはプロトコルの処理分があり、1GbEなら110MB/s前後が目安です。

<!-- FIGURE -->

図で強調した行が、この記事でいちばん伝えたい点です。**無線がどれだけ速くても、通信はNASからPCまでの経路でいちばん遅い区間に揃います。** NASがルーターの1Gbpsポートにつながっていれば、Wi-Fi 7の端末からでも80秒より速くはなりません。逆に、NASを2.5GbE以上でつなげば、近距離のWi-Fi 7端末は有線1GbEを上回る可能性があります。

なお、受け側・送り側のストレージが遅ければ、それも上限になります。HDD1台のNASなら連続読み出しは150〜200MB/s前後が目安で、2.5GbEの312.5MB/sは使い切れません。

## 何を有線にして、何を無線にするか

基本の考え方は、**動かない機器・大きなデータを扱う機器・常に応答してほしい機器は有線、持ち歩く機器は無線**です。

| 機器 | おすすめ | 理由 |
|---|---|---|
| NAS | 有線（できれば2.5GbE以上） | 家じゅうの端末が読み書きする中心。ここが遅いと全員が遅くなる |
| 自宅サーバー・ミニPC | 有線 | 外からのアクセスやコンテナの通信を安定して受ける必要がある |
| デスクトップPC | 有線 | 動かさないうえ、NASとの大容量転送が多い |
| テレビ・レコーダー | 有線（配線できれば） | 高画質の動画を長時間流し続ける。NASの録画やメディアサーバーを見るなら特に |
| 据え置きゲーム機 | 有線（配線できれば） | 大きなダウンロードと、遅延のばらつきの影響を受けやすい |
| メッシュの子機・中継機 | 有線でつなぐ構成が可能なら有線 | 無線で中継すると、その区間の帯域を端末と分け合う |
| スマホ・タブレット | 無線 | 持ち歩くことが前提。Wi-Fi 7対応なら新ルーターの恩恵を最も受けやすい |
| ノートPC | 無線（据え置き時は有線も） | 大容量のコピーをするときだけUSB LANアダプターで有線にする手もある |
| スマート家電・センサー類 | 無線（2.4GHz） | 通信量が小さく、2.4GHz帯にしか対応しない製品が多い |

ルーターのLANポートが足りない、または1Gbpsで遅い場合は、ルーターの近くか、NASを置く部屋にスイッチを1台置くのが簡単です。NASとメインPCを速くしたいなら2.5GbEスイッチ、Wi-Fiのアクセスポイントやカメラに給電も兼ねたいならPoEスイッチが候補になります。PoEについては [PoEスイッチおすすめ比較](/articles/poe-switch-home-network-guide/) を、壁の中の配線がどのカテゴリかで迷ったら [CAT6AとCAT8の違い](/articles/cat6a-cat8-difference-guide/) を参照してください。

## サーバーを無線でつながない理由

ミニPCにはWi-Fiが付いていることが多く、無線のままサーバーとして使うこともできます。それでも有線を勧めるのは、速度よりも「安定」の問題です。

- **遅延がばらつく**：無線は1つの電波を全員で順番に使います。家族が動画を見始めたり、電子レンジや近所の電波と重なったりすると、待ち時間や再送が増えます。平均の速度が十分でも、ときどき応答が遅れることがあります。
- **送受信を同時にできない**：Wi-Fiは同じチャンネルで送信と受信を交互に行います。有線のように、バックアップを受けながら別の端末へ配信する、といった双方向の通信が同時には伸びません。
- **DFSで止まることがある**：5GHz帯の一部のチャンネル（日本のW53・W56）は気象レーダーなどと共用で、ルーターがレーダー波を検知すると、そのチャンネルから移る義務があります。移った先がやはりDFS対象なら、使い始める前に一定時間（通常1分）の確認が入り、その間は通信が途切れます。サーバーにとっては数十秒〜1分の断絶です。
- **省電力で応答が遅れる**：端末側のWi-Fiの省電力機能が働くと、外からの通信への反応が遅れたり、Wake on LANが効かなかったりします。
- **切り分けが難しい**：つながらないとき、原因がサーバーなのか電波なのかを判断しにくくなります。

ルーターとサーバーの間で、遅延のばらつきを確かめる方法もあります。有線と無線それぞれでサーバーに `ping` を打ち、最大値を比べてみてください。

```powershell
# Windowsから50回 ping。「最大」が平均から大きく離れるほど遅延がばらついている
ping -n 50 192.168.1.10
```

## Wi-Fi 7に買い替えなくていい人

次に当てはまるなら、急いで買い替える必要はありません。

- **手元の端末がWi-Fi 7に対応していない**：新しいルーターでも通信はWi-Fi 6以前の方式で、体感はほとんど変わりません。端末を買い替えるタイミングで検討すれば十分です。
- **回線が1Gbps契約で、無線の速度に不満がない**：インターネットの速度は回線で頭打ちになります。Wi-Fi 6の近距離でも、1Gbps回線の実効速度に近い数字は出ることが多いでしょう。
- **Wi-Fi 6／6Eで困っていない**：特に6Eを使っているなら6GHz帯はすでにあり、差は320MHz幅とMLO、4096QAMの部分になります。
- **不満の中身が「NASとの転送が遅い」**：ルーターではなくLANの問題であることが多く、2.5GbEスイッチとNICを足すほうが効きます。
- **電波が届かない部屋がある**：ルーターの規格を上げても、壁や距離の問題は解決しにくいものです。メッシュ子機やアクセスポイントの追加を先に考えます。

反対に、Wi-Fi 5以前のルーターを使い続けている、Wi-Fi 7対応の端末がすでに複数ある、10ギガ回線に乗り換える、といった場合は買い替えの効果が出やすくなります。

## 回線・予算・家の構成別の選び方

| 状況 | 候補 | 理由 |
|---|---|---|
| 1Gbps回線、NASは1GbE、予算1万円以内 | Archer BE220 | 全ポート1Gbpsでも、1Gbps回線・1GbEのNASなら足りる |
| 10ギガ回線（または予定）、NASやPCを2.5GbEにしたい、予算2万円前後 | Archer BE450 | 10G・2.5Gの兼用ポートで、WANとNAS用LANを両立できる |
| 1Gbpsを少し超える回線プラン、国内メーカーのアプリで設定したい | WSR6500BE6P | INTERNETが2.5Gbps。NASを速くするならスイッチを併用 |
| 10ギガ回線、6GHz・320MHz対応の端末がある、無線の端末が多い | WXR9300BE6P | 6GHz・320MHzに対応。NAS用の高速LANはスイッチで作る |
| 10ギガ回線、NASやPCを複数台2.5GbE以上でつなぎたい、セキュリティ機能と長い保証も重視 | RT-BE92U | 2.5Gbps以上のポートが5つ。AiProtectionと3年保証 |

どの候補を選んでも、NASとサーバーは有線でつなぐのが前提です。ルーターのLANが1Gbpsの機種なら、NASのある部屋に2.5GbEスイッチを置く構成と組み合わせると、無線と有線の両方で新しいルーターの良さを活かせます。

## つまずきポイント

- **ONUやホームゲートウェイのLAN側が1Gbps**：10ギガ回線でも、ONU（またはホームゲートウェイ）とルーターの間が1Gbpsでつながっていれば、そこで頭打ちになります。両方のポート表示とリンク速度を確認します。
- **ケーブルが古い**：CAT5（5eではない）のケーブルは2.5GBASE-Tの対象外です。2.5Gbps以上のポートにつないでも、リンクが1Gbps以下に落ちることがあります。
- **ルーターを二重にしてしまう**：ホームゲートウェイにルーター機能がある状態で新しいルーターもルーターとして動かすと、二重ルーターになり、外からサーバーへアクセスする設定（ポート転送など）が複雑になります。どちらか一方をブリッジ（アクセスポイント）モードにします。
- **6GHzにつながらない**：6GHz帯は暗号化方式としてWPA3が必須です。古い設定のままWPA2だけにしていると、6GHz帯が使えないことがあります。
- **ポートの割り当て間違い**：WAN/LAN兼用ポートの機種では、どのポートをWANにするかを設定で選びます。NASを高速ポートに挿したのにWAN扱いのままだと、つながりません。

有線のリンク速度は、Windowsなら次のコマンドで確認できます。2.5GbEの機器なら `2.5 Gbps` と表示されるはずです。

```powershell
Get-NetAdapter | Select-Object Name, Status, LinkSpeed
```

## よくある質問

**Q. Wi-Fi 7ルーターにすれば、NASへのアクセスは速くなりますか？**
無線でつないでいる端末から見ると、端末がWi-Fi 7に対応していて、NASが1Gbpsより速いポートにつながっている場合に限り速くなる可能性があります。NASがルーターの1Gbpsポートにつながっているなら、上限は有線1GbEと同じ125MB/s（理論値）です。

**Q. NASをWi-Fiでつないでもいいですか？**
おすすめしません。NASは家じゅうの端末が使う中心で、遅延のばらつきやDFSによる途切れの影響を全員が受けます。そもそも市販のNASの多くは有線LANでの接続を前提にしています。

**Q. 10G対応ルーターを買えば、家の中が10Gbpsになりますか？**
なりません。多くの製品で「10G」はWAN（インターネット側）のポートを指します。今回の製品でも、WXR9300BE6Pは商品ページに「INTERNETポートのみ10Gbps対応」と書かれています。家の中を10GbEにするには、10GbEのスイッチとNICが必要です。詳しくは [自宅10GbE化の完全ガイド](/articles/home-10gbe-network-guide/) をご覧ください。

**Q. 自宅サーバーを外から使うのに、ルーターの機能は関係しますか？**
ポート転送やVPNサーバー機能を使う場合はルーターの設定が関わります。メーカーの仕様表では、RT-BE92UはWireGuard・OpenVPNなどのVPNサーバーに対応し、WXR9300BE6PもVPNサーバー機能を持ちます（IPv4 over IPv6の回線では使えないとの注記あり）。WSR6500BE6PはVPNサーバー機能に対応していません。TP-Linkの2機種は今回確認していないため、必要ならメーカーの仕様表で確認してください。ルーターのポートを開けずに済む方法として、TailscaleなどのVPNサービスを使う構成もあります。

**Q. メッシュWi-Fiにするなら、子機の間は無線でいいですか？**
無線でも組めますが、子機と親機の間の通信が端末の通信と電波を分け合うため、子機の先では速度が落ちやすくなります。子機まで有線を引ける場所があるなら、有線でつなぐ構成のほうが安定します。

## まとめ

- Wi-Fi 7の320MHz幅・4096QAM・MLOは、端末側も対応していなければ使われない
- 「10G対応」はWAN側の話であることが多い。NASとPCの通信はLAN側で完結し、LANポートの速度が上限になる
- 今回の5製品で、ルーター単体でNAS用の2.5Gbps以上のLANを作れるのはBE450とRT-BE92U。他の3機種はLANが1Gbpsのため、スイッチを足して作る
- NAS・サーバー・デスクトップPCは有線、スマホ・ノートPCは無線、が基本の線引き
- 端末がWi-Fi 7非対応で、不満がNASの転送速度なら、ルーターより2.5GbEスイッチへの投資が先

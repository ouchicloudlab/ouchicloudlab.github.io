## はじめに：なぜ今10GbEなのか

NASでの大容量ファイル転送や仮想化環境の高速化、複数台のサーバー間通信など、homelabを組んでいると必ずぶつかるのが「1GbE（1000Base-T）の遅さ」です。理論値125MB/s程度の1GbEは、SSDを積んだNASや複数台構成では明らかにボトルネックになります。

近年は10GbE対応スイッチやNICの価格がこなれてきたこともあり、自宅ネットワークを10GbE化するハードルは以前よりかなり下がりました。この記事では「何を揃えればいいのか」を整理し、失敗しない構成の考え方をまとめます。

## 10GbE化に必要な3つの要素

自宅を10GbE化するには、大きく分けて以下の3つを揃える必要があります。

1. **10GbE対応スイッチ**（ネットワークのハブ役）
2. **10GbE対応NIC**（PCやNASに挿す・内蔵の通信カード）
3. **対応ケーブル**（RJ45かSFP+かで種類が変わる）

どれか1つでも欠けると10GbEの恩恵は受けられないため、最初に全体構成をイメージしておくことが重要です。

## スイッチ選びのポイント

### RJ45（Base-T）タイプかSFP+タイプか

10GbEスイッチには、既存のLANケーブル（カテゴリ6A以上）がそのまま使える**RJ45タイプ**と、光や専用ケーブルで接続する**SFP+タイプ**があります。

- **RJ45タイプ**：配線の自由度が高く初心者向き。ただし発熱が大きく、ポート単価も高め。
- **SFP+タイプ**：省電力・低発熱でポート単価も安いが、DAC（銅線）ケーブルやSFP+モジュールが別途必要。

自宅の配線をそのまま活かしたいならRJ45、ラック内でNASとサーバーを直結するような用途ならSFP+が向いています。

### ポート数と全ポート10GbE対応かを確認

安価なスイッチには「10GbEポートは2つだけで残りは1GbE」という製品も多くあります。10GbE化したい機器の台数分、必ず10GbE対応ポートがあるか確認しましょう。将来的な拡張を見込んで、少し余裕のあるポート数を選ぶのがおすすめです。

### ファンレスかどうか

自宅・寝室に置く場合は、ファンレス設計またはファン制御が優秀な機種を選ぶと静音性が確保できます。ラックマウントして別室に置ける環境なら、冷却重視のファン付きモデルでも問題ありません。

## NIC選びのポイント

### PCIe接続 or M.2/USB接続

デスクトップPCやサーバー機には**PCIe接続の10GbE NIC**を増設するのが基本です。ミニPCなど拡張スロットがない機種では、USB接続の10GbEアダプタや、対応するM.2スロットを使うタイプの製品も選択肢になります。

### チップセットの安定性

10GbE NICはIntel系チップ（X550/X710など）とRealtek系・Aquantia（Marvell）系チップが主流です。Linuxやフリーのnasネットワーク環境（TrueNASなど）で使う場合は、ドライバの安定性からIntel系チップが無難とされることが多い一方、価格重視ならRealtek系も選択肢に入ります。事前に使用予定のOS・NASでの動作実績を確認しておくと安心です。

### NAS側の対応も確認

NAS本体に10GbEポートが標準搭載されているか、拡張カードスロットで後付けできるかはメーカー・機種によって異なります。購入前に対応拡張カードのメーカー純正リストを確認しましょう。

## ケーブル選びのポイント

### RJ45構成の場合

10GBase-Tを安定して通すには**カテゴリ6A（Cat6A）以上**のLANケーブルが推奨されます。Cat6でも短距離（数m程度）なら通ることがありますが、距離が伸びるほど不安定になりやすいため、新規に配線するならCat6A以上を選んでおくと安心です。

### SFP+構成の場合

ラック内など短距離の接続には**DAC**（Direct Attach Cable）と呼ばれる銅線ケーブルが低コストで扱いやすい選択肢です。距離が離れる場合や柔軟な配線が必要な場合は、光モジュール（SFP+トランシーバー）と光ファイバーケーブルの組み合わせを使います。

## 構成例：小規模homelabの場合

- 10GbE SFP+スイッチ（8ポート前後）
- NAS：内蔵または拡張カードで10GbE対応
- メインPC：PCIe接続の10GbE NIC
- NASとスイッチ間：DACケーブルで直結
- PCとスイッチ間：距離があるためCat6A＋RJ45タイプのポートを利用

このように、機器ごとに適した接続方式を組み合わせるハイブリッド構成もよく使われます。

## 導入前に確認しておきたい注意点

- **消費電力・発熱**：10GbE機器は1GbEに比べて発熱・消費電力が大きい傾向があります。設置場所の換気を確保しましょう。
- **実効速度は理論値通りにならない**：ストレージ側の読み書き速度がボトルネックになるケースも多く、10GbE化してもNASのディスク構成（SSDかHDDか、RAID構成）によっては恩恵が限定的です。
- **予算配分**：スイッチ・NIC・ケーブルすべてを一度に揃えると出費がかさむため、まずはNASとメインPC間だけを10GbE化するなど、段階的な導入もおすすめです。

## 費用の目安：構成別に計算する

10GbE化は「スイッチが高い」と思われがちですが、実際にはNIC・ケーブル・トランシーバまで含めた総額で見る必要があります。

| 構成 | 内訳 | 費用の目安 |
|---|---|---|
| **最小構成**（NAS↔PC 直結・スイッチなし） | NIC × 2 + DACケーブル 1本 | 20,000〜35,000円 |
| **SFP+スイッチ構成** | 8ポートSFP+スイッチ + NIC × 2 + DAC × 2 | 60,000〜90,000円 |
| **RJ45スイッチ構成** | 4〜8ポート10GBase-Tスイッチ + NIC × 2 + Cat6Aケーブル | 70,000〜120,000円 |
| （参考）2.5GbE 標準構成 | スイッチ + NIC × 2 | 15,000〜20,000円 |

**注目すべきは最小構成です。** スイッチを買わずにNASとPCを1本のDACケーブルで直結すれば、2〜3万円台で10GbEの速度が得られます。それぞれの機器に既存の1GbEポートを残しておけば、インターネット接続はこれまでどおり使えます。

「NASとメインPCの間さえ速ければいい」という要件は多いので、**まずは直結から始めるのが最も費用対効果が高い**構成です。

## 消費電力と発熱：10GbEの隠れたコスト

10GbEは1GbEと比べて消費電力が大きく、24時間稼働の自宅サーバーでは無視できません。

| 機器 | 消費電力の目安（1ポートあたり） |
|---|---|
| 1GbE ポート | 約0.5W |
| 2.5GbE ポート | 約1W |
| **10GBase-T（RJ45）ポート** | **2〜5W** |
| **SFP+（DAC接続）** | **約1〜1.5W** |
| SFP+（光モジュール） | 約1〜2W |

**10GBase-T（RJ45）は、SFP+の2〜4倍の電力を消費します。** これは規格上、より複雑な信号処理を行うためです。8ポートすべてを10GBase-Tで埋めると、スイッチだけで30〜40W級になることもあります。

```
30W × 24h × 365日 ÷ 1000 × 31円 ≒ 年間8,150円
```

**省電力と静音を優先するなら、SFP+ ＋ DACケーブルの構成が有利です。** 一方、既存のLAN配線をそのまま使いたい・配線の取り回しを自由にしたい場合はRJ45が勝ります。この消費電力差は、自宅サーバー用途では判断材料として大きいポイントです。

発熱も同様で、10GBase-TのNICは動作中にかなり熱くなります。ミニPCの狭い筐体内では、**NIC自体の熱でSSDの温度が上がる**こともあるため、エアフローに注意してください。

## 中古のエンタープライズ機材という選択肢

10GbEの世界では、データセンターから放出された中古機材が安価に流通しています。

- **Mellanox ConnectX-3 / ConnectX-4** などのSFP+ NICが数千円で入手できることがある
- 中古のSFP+スイッチも、新品の半額以下で見つかることがある

コストを抑える有効な手段ですが、**自宅サーバー用途では次の点に注意してください**。

1. **ファン騒音**：エンタープライズ向けスイッチは冷却優先の設計で、居室に置けるレベルの騒音ではないことがあります。
2. **消費電力**：業務用機材は常時50W以上消費するものもあり、電気代で元が取れなくなります。
3. **ドライバの対応状況**：古い世代のNICは、最新のOSでドライバのサポートが打ち切られている場合があります。購入前に、使用予定のOSでの動作報告を確認してください。
4. **保証がない**：故障時は自己責任です。

**安く手に入るが、静かで省電力とは限らない**——というのが実情です。別室やガレージに設置できる環境なら有力な選択肢になります。

## 速度が出ないときに確認する5つのこと

10GbE化して最も多いトラブルが「10Gbpsでリンクしているのに、実測が2〜3Gbpsしか出ない」というものです。原因は概ね次のどれかです。

### 1. まずネットワーク単体で測る

```bash
# 受信側
iperf3 -s
# 送信側
iperf3 -c 192.168.1.10 -P 4
```

`-P 4` は並列4ストリームでの測定です。**単一ストリームでは10Gbpsを出しきれないことがある**ため、並列で測ると本来の能力が見えます。ここで9Gbps前後出ていれば、ネットワークは正常です。

### 2. ストレージ側がボトルネックになっていないか

10GbE（約1,100MB/s）を活かすには、転送元・転送先の両方がその速度で読み書きできる必要があります。

- 3.5インチHDD単体：150MB/s前後 → **10GbEの意味はほぼない**
- HDD 4台のRAID5：300〜500MB/s → 半分程度は活かせる
- SATA SSD：約500MB/s → 半分程度
- **NVMe SSD：1,500MB/s以上 → 10GbEを活かせる**

**10GbEが本当に効くのは、両端がNVMe SSDの場合**です。HDDベースのNASを10GbE化しても、体感はあまり変わりません。

### 3. CPUがボトルネックになっていないか

10GBase-T の通信は、思いのほかCPUを使います。省電力な低TDPのCPUでは、通信処理だけでコアを使い切ってしまうことがあります。転送中にCPU使用率を確認してみてください。

### 4. ジャンボフレームを検討する

MTUを標準の1500から9000に上げると、パケット数が減りCPU負荷が下がります。ただし、**経路上のすべての機器で同じ設定にする必要があります**。1台でも設定漏れがあると、通信が不安定になったり、逆に遅くなったりします。効果は環境次第（数%〜20%程度）なので、まず標準設定で動かしてから試すことをおすすめします。

### 5. SMBの設定を確認する（Windows↔NAS）

Windows と NAS 間のファイル共有では、**SMB Multichannel** が有効かどうかで速度が変わります。また、ウイルス対策ソフトのリアルタイムスキャンが転送速度を大きく落とすことがあるため、切り分けの際は一時的に無効化して比較してみてください。

## 段階的な導入をおすすめする理由

10GbEは一式を揃えると10万円前後の投資になります。一方で、**実際に恩恵を受けられる場面は限定的**です。おすすめの進め方は次のとおりです。

1. **まず [2.5GbE化](/articles/home-2-5gbe-network-2026/) を試す**（1.5〜2万円で、1GbEの2.5倍）
2. それでも足りないと感じたら、**NASとメインPCだけをDAC直結で10GbE化**（2〜3万円）
3. 接続したい機器が3台以上になったら、**初めてスイッチを買う**

この順序なら、途中で「思ったほど速くならなかった」と気づいたときの損失を小さく抑えられます。

## よくある質問

**Q. 10GbEにすればインターネットも速くなりますか？**
なりません。家庭内LANの速度と、インターネット回線の速度は別物です。10Gbpsのインターネット回線を契約している場合のみ、ルーターのWAN側とLAN側の速度が意味を持ちます。

**Q. 10GbEと2.5GbE、体感の差はどれくらい？**
100GBのファイルを転送した場合、理論上は1GbEで約15分、2.5GbEで約6分、10GbEで約1分30秒です。ただし前述のとおり、**ディスク側が追いつかなければこの差は出ません**。HDDベースのNASでは、2.5GbEと10GbEでほとんど差が出ないこともあります。

**Q. Cat6のケーブルが余っているのですが使えますか？**
短距離（〜55m程度）であれば10GBase-Tが通ることが多く、自宅の配線距離なら実用上問題ないケースが大半です。ただし規格上の保証はCat6Aからなので、不安定な場合はケーブルを疑ってください。

**Q. ミニPCでも10GbE化できますか？**
機種によります。PCIeスロットやOCuLink端子を持つ機種（Minisforum MS-01 など）は増設可能です。スロットのない機種では、USB4/Thunderbolt接続の10GbEアダプタという選択肢もありますが、価格が高く発熱も大きめです。**最初から10GbEポートを内蔵した機種を選ぶ**のが確実です。詳しくは [自宅サーバー向けミニPCおすすめ5選](/articles/mini-pc-osusume-2026/) をご覧ください。

## まとめ

自宅10GbE化は「スイッチ・NIC・ケーブル」の3点をどう組み合わせるかが肝心です。

- **RJ45（10GBase-T）は配線が自由だが、消費電力がSFP+の2〜4倍**。24時間稼働では年間の電気代に効いてくる
- **SFP+ ＋ DACケーブルは省電力・低発熱・低コスト**。ただし配線距離と柔軟性で劣る
- **NAS↔PC のDAC直結なら2〜3万円**から始められる
- **10GbEが本当に効くのは、両端がNVMe SSDの場合**。HDDベースのNASでは体感差は小さい
- 中古のエンタープライズ機材は安いが、**騒音・消費電力・ドライバ対応**を確認してから
- まずは [2.5GbE](/articles/home-2-5gbe-network-2026/) を試し、足りなければ段階的に10GbEへ

段階的に導入すれば、初期費用を抑えながら着実にネットワーク環境を強化できます。
